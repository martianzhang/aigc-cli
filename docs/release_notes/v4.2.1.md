# Release Notes v4.2.1

> Chat 新增 **`@file` 文件引用**：文本文件内联进消息，图片作为多模态附件发送。`@` 与 `read` 工具**共用同一套安全策略**，二进制/超限文件一律拒绝内联。

## Highlights

### 📎 `@file` 文件引用

在消息里用 `@path` 引用本地文件，不必手动把内容贴进对话。

```bash
# 交互式：输入 @ 后按 Tab 补全路径
aigc-cli chat
>>> 帮我 review @internal/cli/chat/chat.go

# 非交互式同样支持
aigc-cli chat --message "解释 @main.go"
```

| 文件类型 | 行为 |
|---|---|
| 文本文件 | 原样内联为 `<file name="路径">内容</file>` |
| 图片（png / jpeg / gif / webp） | 作为图片附件发送（base64）；正文保留 `[attached image: 路径]` 标记，需使用支持视觉的模型 |
| 二进制文件 | 不内联，原样保留 `@路径` 并给出警告 |
| 文本 > 1 MiB / 图片 > 20 MiB | 拒绝内联或附加，给出警告 |
| 解析不到的 token | 原样保留（`@用户名`、`@scope/pkg` 不会被误当成路径） |

只识别「行首或空白之后的 `@`」，且**文件确实存在**才展开，因此邮箱地址与 npm 作用域包名不受影响。

### ⌨️ Tab 补全

输入 `@` 后按 `Tab` 循环匹配项目文件，支持句中补全（`explain @src/ma` + `Tab`）。git 仓库内走 `git ls-files`（**遵循 `.gitignore`**），1 秒超时后回退为跳过隐藏条目的目录遍历；索引懒加载并缓存，仅在首次按 Tab 时构建。

### 🛡 安全边界（与 `read` 工具一致）

| 机制 | 说明 |
|---|---|
| `defaults.chat.read_deny` | `@` 读取与 `read` 工具**共用同一个正则黑名单**；命中时**不读取文件**，只显示警告 |
| 二进制嗅探 | 与 `read` 相同（NUL 字节或 >1% 非法 UTF-8），二进制文件不会作为文本灌进上下文 |
| 大小上限 | 文本 1 MiB / 图片 20 MiB |
| 作用范围 | 仅对**用户消息**生效；工具调用参数里的 `@` 由既有逻辑展开 |

> 设计取舍：`@` **不做 cwd 越权限制**，与 `read` 工具行为保持一致，统一由 `read_deny` 兜底，避免出现两套互相矛盾的访问语义。

## 实现要点

- **`internal/agent`**：新增 `ReadFileRaw(path, deny)`（复用 `deniedByReadPolicy` 后返回原始字节）与导出的 `LooksBinary`，让 `read` 工具与 `@` 展开共用同一条读取/拒绝/嗅探路径。
- **`internal/types`**：新增 `ChatImage{Name, MIMEType, Data}` + `DataURI()`；`ChatMessage` 增加 `Images`（`json:"-"`）并实现 `MarshalJSON` —— 无图片时输出与改动前**逐字节一致**（`content` 为空则省略），有图片时 `content` 变为 parts 数组。`AnthropicMessage` 同样改为自定义 `MarshalJSON`（纯文本仍是字符串，带图时输出 `{"type":"image","source":{…base64}}` 块）。
- **三条 provider 分支**：OpenAI 标准走 `ChatMessage.MarshalJSON`（`image_url` data URI）；Anthropic 由 `buildAnthropicRequest` 透传 `Images`；Responses API 在 `translateMessageToResponsesItem` 输出 `input_text` / `input_image`。
- **`internal/cli/chat`**：新增 `mentions.go`（`expandMentions` + 图片类型嗅探）与 `fileindex.go`（`git ls-files` / 目录遍历回退）；`handleTabCompletion` 增加 `@` 分支；`handleUserMessage`（TUI）与 `flagMessages`（非交互）分别接线，显示区仍显示用户原文。
- **`internal/agent/compact`**：`EstimateHistoryTokens` 将图片按字节数折算（`len/3`），避免带图对话绕过自动压缩。
