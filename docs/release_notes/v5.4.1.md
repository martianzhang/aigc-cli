# Release Notes v5.4.1

> 以「修复各平台发布包的架构错误与本地音频库加载」为主的补丁版本。
> 同时合入 v5.4.0 之后的 redact `--stdout` 预览功能。

## Highlights

### 📦 发布包修复（Linux / macOS）

此前各平台压缩包存在三类问题，本次全部修复：

- **架构错配**：`linux-amd64` / `darwin-amd64` 包内混入了 ARM64 的
  sherpa-onnx / onnxruntime 原生库；`darwin-amd64` 包内的二进制与 helper
  实际也是 arm64 产物。现在每个包只包含与目标架构一致的二进制、helper 和原生库。
- **解压路径错误**：原生库曾被塞进绝对路径（`home/runner/go/...`），
  解压后不在可执行文件同级目录，导致本地 TTS / ASR 报 `dependencies missing`。
  现在包内为扁平结构：二进制与 `libaigc-sherpa-helper.*`、
  `libsherpa-onnx-*.so` / `.dylib` 均在同一层。
- **macOS 包体积**：去掉与版本化文件完全相同的 `libonnxruntime.dylib`，
  只保留 `libonnxruntime.1.27.0.dylib`，方便确认当前 ONNX Runtime 版本。

校验更新后的包：

```bash
tar tzf aigc-cli-linux-amd64.tar.gz   # 所有文件都在同一层
lipo -archs aigc-cli-darwin-amd64     # x86_64
```

### 📄 Redact 文档预览（--stdout）

`redact apply --stdout` 之前只支持纯文本输入；现在 DOCX / PDF / 图片也可以
只打印脱敏预览、不写文件：

```bash
aigc-cli redact apply complaint.docx --stdout --mapping complaint.map.json
aigc-cli redact apply judgment.pdf --stdout --dpi 300
aigc-cli redact restore complaint.redacted.docx --stdout --mapping complaint.map.json
```

- DOCX 复用 `apply` 的实际替换结果，打印内容与写出的 `.docx` 一致，仍可还原；
- PDF / 图片打印按 `style` 替换后的文本（文件输出仍是黑块）；
- 不产生输出文件；`restore --stdout` 同样只打印不写文件。

## 升级提示

- 使用本地 TTS / ASR 的用户请重新解压完整发布包，确保二进制与原生库在同一目录，
  不要只替换可执行文件；
- 全量测试、`go vet`、`golangci-lint` 均通过。
