# Release Notes v5.0.1

> 以「非交互模式更安全、chat 更顺手」为主的补丁版本。
> 本次重点：chat 成为根命令默认行为、工具确认在非交互模式下 fail-closed、
> ideas 支持稳定 ID 与 `--prompt-only`，以及一批跨平台 / 超时修复。

## ⚠️ 行为变化

### 非交互 chat 的工具确认改为 fail-closed

之前 `confirm_tools` 只在 TUI 中生效；`--message`、管道和位置参数等非交互路径会直接执行
`bash` / `write` / `edit`，看起来像绕过了确认规则。

现在默认行为改为：

- TUI：仍然逐次确认；
- 非交互：命中 `confirm_tools` 的工具**不执行**，模型收到一条 blocked 工具结果，并提示用户
  加 `--yes` 或改用交互模式；
- `--yes` / `-y`：TUI 和非交互模式都会自动放行命中规则的工具。

```bash
# 非交互：bash 默认被拦截
aigc-cli "今天几号？"

# 明确放行工具
aigc-cli --yes "今天几号？"

# TUI 中也跳过确认
aigc-cli --yes
aigc-cli --interactive --yes
```

配置 `confirm_tools: []` 仍然表示完全关闭确认。

**升级提示**：如果有脚本依赖非交互模式下隐式执行 `bash` / `write` / `edit`，需要显式加
`--yes`，或把 `defaults.chat.confirm_tools` 显式设为 `[]`。

### 根命令默认就是 chat

不带子命令时，`aigc-cli` 现在完整等同于 `aigc-cli chat`：

```bash
aigc-cli                                    # 交互式 TUI
aigc-cli --save                             # 交互式并保存 session
aigc-cli --session <id|file>                # 恢复 session
aigc-cli "Hello, who are you?"              # 单轮聊天
aigc-cli -p "en to zh" "hello"              # 指令 + 位置参数
echo "hello" | aigc-cli -p "en to zh"       # 管道 + 指令
```

消息顺序固定为：`--message` / `--prompt` → 位置参数 → 管道 stdin。
`--interactive` 不能和位置参数同时使用。

### 移除默认 system prompt 中的当前日期

TUI 的默认 system prompt 不再包含「今天是 …」。日期每天变化会破坏 prompt 前缀缓存，
而且写进 session 后会停留在创建当天。需要日期时，有 bash 的模型可以执行 `date`；
严格只读场景没有内置日期来源（与 Pi 的行为一致）。

## Highlights

### 💡 ideas：稳定 ID、`--id` 与 `--prompt-only`

- 每条结果打印稳定的 12 位十六进制 ID；数据集提供 `id` 字段时优先使用，否则由
  `source_url` + `prompt` 计算。
- 新增 `--id`：按 ID 取回本地数据集中的某条灵感（大小写不敏感）。
- 新增 `--prompt-only`：只输出提示词正文，便于管道传给 `aigc-cli image -p`。
- 修复不带关键词时 `--limit` 被强制改为 1 的问题；现在 `--random --limit 3` 会返回 3 条，
  只有完全裸跑 `aigc-cli ideas` 才默认随机 1 条。

```bash
aigc-cli ideas --random --limit 1 --prompt-only
aigc-cli ideas --id 1a2b3c4d5e6f --prompt-only
aigc-cli image -p "$(aigc-cli ideas --id 1a2b3c4d5e6f --prompt-only)"
```

### 🖥️ chat：跨平台 bash 与代理继承

- Windows 优先使用 Git Bash / MSYS2 / Cygwin / busybox，其次 PowerShell 7、Windows
  PowerShell 5.1、`cmd.exe`；拒绝 WSL bash 以避免路径不一致。
- PowerShell / cmd 回退时会翻译常见 Unix 惯用法（`/dev/null`、`ls -la`、`find -name`、
  `grep -rn`、`head`/`tail`、`rm -rf`、`mkdir -p` 等）。
- bash 子进程继承生效的 `http_proxy` / `--no-proxy`，并写入 HTTP(S)/ALL_PROXY 环境变量。
- TUI 顶栏改为显示当前工作目录，模型名继续留在状态栏。

### ⏱️ 超时参数在各 HTTP 通道生效

`--timeout` / `defaults.*.timeout` 之前在多条链路上被忽略或覆盖，现在统一生效：
OpenRouter 图片、ModelScope 提交/轮询、Ollama 原生图片、上传、OCR/vision/detect、SFX、
SoMark 解析、ideas 下载、models 发现和 chat。

各通道在用户未配置超时时仍保留自己的合理默认值（例如 SoMark 15 分钟）。

### 🖼️ OfoxAI：只对 GPT Image 系列固定 openai provider

`gpt-image` 系列继续固定到 `openai`，避免 azure_foundry 更严格的审核；其他 OfoxAI 图片模型
不再被错误固定，交给网关路由。

## 修复

- `max_iterations` 默认值从 10 提升到 100；达到上限时 TUI 和非交互模式都会明确提示。
- 修复 MCP `safeFileToken` 在 Windows 与其他平台上不一致的问题。
- 修复 Windows 下的测试与路径兼容问题（vision、session、webfetch）。
- CI 现在在 Linux、macOS、Windows 三端运行完整测试。

## 升级提示

- 非交互脚本如果依赖隐式执行 `bash` / `write` / `edit`，请加 `--yes`。
- 需要保留旧的无确认行为时，可显式配置：

  ```yaml
  defaults:
    chat:
      confirm_tools: []
  ```
