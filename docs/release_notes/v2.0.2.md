# v2.0.2 — MCP 工具名规范化

> 统一所有 MCP/Chat 工具命名为 `verb_noun` 格式，消除歧义。

## 🔧 改名

| 旧名 | 新名 | 原因 |
|---|---|---|
| `ocr_text` | `recognize_text` | 违反 `verb_noun` 规范 |
| `describe_image` | `caption_image` | 与 AI 看图说话（vision --describe）混淆 |
| `ideas`（Chat 工具） | `search_ideas` | 与 MCP 工具名不统一 |

## 📄 文档

- `docs/guide-mcp.md`、`docs/guide-ocr.md`、`docs/config.example.yaml` 同步更新
- release notes 保持历史原貌，不回溯修改

## ⚠️ 不兼容变更

使用旧工具名 `ocr_text`、`describe_image`、`ideas` 的 MCP 客户端（Claude Desktop、Cursor 等）和 Chat 配置需要更新为新名称。
