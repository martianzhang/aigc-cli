# Release Notes v3.0.2

> **本次为纯重构版本**：无新增功能、无行为变更、无命令行/配置/输出变更。
> 命令、参数、配置文件、输出与 v3.0.1 **完全兼容**，升级无需任何调整。

## 重构：`cmd` 目录结构整理

将原先扁平的 `package cmd`（104 个文件、约 20,600 行）整理为「命令子包 + 共享包」结构：`cmd/` 只保留命令注册 shim 与入口装配，**从约 20,600 行缩减到约 780 行**。

### 一、拆分超大文件

按职责把超长文件拆到单文件 ~250 行以内，例如：

- `chat_exec.go`（1280 行）→ 10 个文件
- `detect_runner.go`（714 行）→ 6 个文件
- `ocr.go`（616 行）→ 4 个文件
- `audio.go` + `audio_init.go`（542/528 行）→ 6 个文件

同时清理含糊命名（去掉 `_extra` / `_shared` / `_defs` 等无意义后缀）。

### 二、业务逻辑下沉

- 新增 `internal/detect`：图像信号分析（FFT/噪声/JPEG 双量化）+ 评分/解析 helper
- 新增 `internal/agent`：agent 工具定义表、会话压缩、KB/文件/grep/shell 工具执行器
- 图像解码/转换管线迁入 `internal/service`

### 三、命令组子包化

- 新增共享包：
  - `internal/cli/options`：全局 `Shared` 状态、配置访问器、`ConfigDir`/`WatermarkDir`、`NewClient`/`ApplyTimeout`、flag helper、`Stdout`/`Stderr` 注入、`IsToolAllowed`、Provider 常量
  - `internal/service`：下载 / 颜色 / 音频 / 输入 / 用量等跨命令共享 helper
- 全部命令组迁入 `internal/cli/*`：`task`、`balance`、`preview`、`ideas`、`depth`、`models`、`knowledge`、`background`、`ocr`、`audio`、`music`、`video`、`image`、`midjourney`、`detect`、`vision`、`chat`（含交互式 TUI）、`mcp`
- 各子包通过显式注入（`Deps` / 参数）依赖共享状态，**不反向 import `cmd`，零 import 循环**

## 影响

- **用户可见行为无变化**：命令、参数、配置文件、输出格式与 v3.0.1 一致
- 仅为内部结构重构，便于维护、测试与后续扩展

## 验证

- `make build` / `make test`（43 个包全绿，0 失败）/ `make lint`（0 issues）
- 全部命令冒烟通过
