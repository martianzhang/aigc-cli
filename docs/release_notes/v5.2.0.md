# Release Notes v5.2.0

> 以「Chat 上下文管理 / 交互式模型切换」与「GPT Image 2.6 GIF 原生输出」为主的次版本。
> 同时包含工具输出上限与 TUI 渲染性能改进。

## Highlights

### 🎞️ Image：GPT Image 2.6 动画 GIF 原生支持

OpenAI Images 2.6 起，`POST /v1/images/generations` 支持 `output_format=gif`。CLI 现在原生支持，
不再需要用 `--inject-json` 拼参数：

```bash
aigc-cli image -P ofox -m openai/gpt-image-2.6-flare \
  -p "a tiny red ball bouncing on white, seamless loop" \
  --output-format gif --frame-count 9 --frame-duration-ms 200 --size auto
```

新增参数：

| 参数 | 说明 |
|---|---|
| `--output-format gif` | 输出动画 GIF（GPT Image 2.6+） |
| `--frame-count` | 帧数 2-64，默认 9 |
| `--frame-duration-ms` | 每帧时长 20-2000ms，默认 200，API 按 10ms 取整 |
| `--complexity` | 规划投入 `low` / `medium` / `high`（GPT Image 2.6+） |

行为细节：

- `gpt-image-2.5` / `gpt-image-2` 等旧模型请求 GIF 会直接报错并提示使用 2.6+；非 `gpt-image`
  系列模型交由服务端判断；
- 帧参数必须配合 `--output-format gif`；GIF 不支持 `--output-compression`；
- GIF 只支持文生图，`/images/edits` 不支持，带参考图自动走 edits 时会明确报错；
- 未指定 `--size` 时 GIF 自动使用 `auto`（静图仍默认 `1:1`）；
- 保存时按魔数自动写成 `.gif`；
- `defaults.image.complexity` / `frame_count` / `frame_duration_ms` 与 MCP `generate_image`
  同步支持。

厂商兼容性（2026-11 实测）：

| Provider | GIF 输出 | 帧参数 |
|---|---|---|
| OpenAI 原生 / Azure OpenAI | ✅ | ✅ |
| OfoxAI（`ofox.ai` / `ofox.run` / `ofox.io`） | ✅ | ❌ 会被忽略，始终返回默认 9 帧 × 200ms |
| OpenRouter | ❌ Image API 仅接受 `png`/`jpeg`/`webp`/`svg`，CLI 发送前即报错 | ❌ 未声明相关参数 |
| APIMart / Gemini / ModelScope / Agnes | ❌（各自协议不转发 GIF 参数） | ❌ |

> OpenRouter 的 `--json` 逐字透传仍原样发送，便于其后续开放 GIF 时直接验证。

### 🧠 Chat：检查点式压缩与模型感知上下文窗口

- 压缩不再丢掉整段历史：保留最近 `keep_recent_tokens` 的原文尾部，摘要只覆盖切点之前的内容；
- 再次压缩时基于上一版摘要**增量更新**，并自动追加 read / modified 文件清单；
- 摘要使用固定结构（Goal / Progress / Key Decisions / Next Steps 等），工具结果截断后序列化为文本；
- 上下文窗口解析顺序：命令行/配置 > 会话显式值（仅同模型）> 模型/Provider 覆盖 > 内置模型表
  > provider `/models` 探测 > `fallback_context_window`（默认 128000）；
- 新增 `/context` 查看占用、阈值、分类明细、usage 锚点和上次压缩收益；
- `/compact [关注点]` 支持手动压缩并指定摘要重点；
- 摘要瞬时错误自动重试；主请求上下文溢出时强制压缩并重试一次，仍失败则本地紧急裁剪；
- `compaction` 记录保存原因（`threshold` / `manual` / `overflow` / `emergency`）、摘要模型、
  usage 和文件清单；
- 新增 `--reserve-tokens`、`--keep-recent-tokens`、`--no-auto-compact` 及对应配置项。

### ⌨️ Chat TUI：`/provider` 与 `/model` 交互式切换

- `/model` 列出当前 provider 的模型目录（含上下文窗口），`/model <名称>` 切换模型，
  `/model <provider> <名称>` 一步切换 provider + 模型，Tab 补全 provider/模型；
- `/provider` 列出并切换 `providers.<name>`；新 provider 配了 `model` 就用它，否则保留当前模型；
- 切换会立即重建客户端、重新解析上下文窗口并保留历史对话；
- 会话 JSONL 新增 `model` 记录；恢复时若 CLI/config 未显式指定，沿用会话最后一次切换；
- 交互式切换跳过同步 `/models` 探测，TUI 活跃期间不向终端泄漏 stderr；
- 命令输入框在每次命令后清空；空输入框在 placeholder 换行时仍保持一行。

### ⚡ 性能：工具输出上限与 TUI 渲染

- bash 执行输出与所有工具结果统一限制为 1 MiB，超出部分流式丢弃并标记；
- 工具输出进入对话历史前按 `session_tool_output_max_bytes`（默认 32 KiB）截断；
- 用 `ansi.Truncate` 替换逐字符裁剪，工具摘要扫描限制在 4 KiB，TUI 分行/计数不再分配完整结果；
- 展开的工具卡片最多渲染 2000 行；
- 新增裁剪、摘要、TUI 渲染、输出上限与会话追加的 benchmark，以及 `make bench` 目标。

## 升级提示

- 无破坏性变更；不配置新参数时行为与 v5.1.0 一致。
- GIF 输出仅 GPT Image 2.6+ 可用；旧版 GPT Image 模型会得到明确报错。
- OpenRouter 暂不支持 GIF，请使用 OpenAI 家族或 OfoxAI；OfoxAI 当前会忽略帧参数。
