# v2.1.1 — ModelScope 图片生成 + 显示优化

## 新功能

### ModelScope 异步图片生成

ModelScope 的 AIGC 模型（如 Krea-2-Turbo）使用异步任务模式，与标准 OpenAI 接口不兼容。新增完整支持：

- 自动检测 `api-inference.modelscope.cn` / `.ai` 域名
- 异步提交 → 轮询 → 下载全流程
- 支持 `--size`、`--negative-prompt` 等 ModelScope 原生参数

```bash
aigc-cli image -p "a cat" --provider modelscope --model krea/Krea-2-Turbo
```

## Bug 修复

### `isOllama` 路由错误（影响所有非 APIMart/OpenRouter 的命名 Provider）

`cmd/image.go` 中 `isOllama` 变量使用了 `provider.IsOnlineProvider(p)`，该函数对任何有 `Name` 的 provider 返回 `true`，导致配置为 `type: openai` 的 ModelScope（以及任何自定义命名 Provider）被错误路由到 Ollama 的 `/api/generate` 端点。

**修复：** 改为检查 `p.Type == types.ProviderOllama || provider.IsLocalEndpoint(p.BaseURL)`。

### `--print-config` 标注错误

嵌套在 `providers.*` 下的 `base_url` 字段被错误地标注为全局 provider 的检测结果（如 `# APIMart`），即使该 provider 完全不同（如 modelcope / openrouter）。

**修复：** 移除了 YAML 内联的 `base_url`/`api_key` 标注，各命令的有效 Provider 概览已在下文独立展示。
