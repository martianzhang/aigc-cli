# Release Notes v2.5.0

## New Features

### 独立 `depth` 命令（图片 + 视频 → 灰度深度图）

深度转换从 `video --convert-to-depth` 升级为**独立命令 `aigc-cli depth`**，
现在同时支持**单张图片**和**视频**，输入类型按扩展名自动识别：

```bash
# 首次使用：安装 ONNX Runtime + 默认深度模型（depth-anything-v2-small，Apache-2.0）
aigc-cli depth init

# 单张图片 → 灰度深度图 PNG（无需 ffmpeg，约 1-3 秒）
aigc-cli depth -i photo.jpg

# 视频 → 灰度深度视频 MP4（需要 ffmpeg）
aigc-cli depth -i video.mp4

# 常用选项
aigc-cli depth -i photo.jpg --invert    # 近暗远亮
aigc-cli depth -i photo.jpg --preview   # 生成后用系统查看器打开
aigc-cli depth -i video.mp4 --start-time 00:01:00 --end-time 00:01:30
aigc-cli depth -i photo.jpg --dry-run   # 只打印将执行的命令
```

- 深度估计完全**本地 ONNX 推理**（Depth Anything V2），无需 API Key、无需联网
- 图片默认推理分辨率 518（14 对齐）；视频默认 280（快），`--size 378/518` 换更高质量
- 支持 `--invert`、`--no-smooth`、`--keep-audio`、`--encode-args`（自定义 ffmpeg 编码）
- 图片输入支持 png/jpg/jpeg/webp/bmp/gif/avif/heic/jxl，视频支持 mp4/mov/mkv/avi/webm

### 工具改名：`convert_video_depth` → `convert_depth`

MCP 与 Chat Agent 工具重命名为 `convert_depth`，并升级支持图片 + 视频自动路由
（图片 → PNG，视频 → MP4）。配置中 `tools_enable` / `tools_disable` 白名单需要同步更新。

### 破坏性变更

- **移除 `video --convert-to-depth`**：请改用 `aigc-cli depth -i video.mp4`（flag 一一对应）
- **移除 `video init`**：请改用 `aigc-cli depth init`
- **`convert_video_depth` 工具改名 `convert_depth`**：白名单配置同步更新

## Performance

- 图片推理约 1-3 秒（CPU），单图无需 ffmpeg，体验大幅简化
