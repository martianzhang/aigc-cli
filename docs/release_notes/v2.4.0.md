# Release Notes v2.4.0

## New Features

### WASM Codec Image Enhancement (零 CGO)

图片编解码全面升级，基于 wasm codec（jpegli / libwebp / libavif / libjxl），
无需 CGO 编译环境即可获得工业级编码器。

#### 新解码格式（AVIF / HEIC / JXL）

所有图片处理命令（`detect` / `ocr` / `vision` / `background` / MCP 工具）
现在都能直接解码 **AVIF / HEIC / JPEG-XL** 图片，包括 iPhone 相册的 HEIC：

```bash
# 手机相册的 HEIC 图直接检测
aigc-cli detect photo.heic

# AVIF/JXL 图片 OCR
aigc-cli ocr scan image.avif
```

#### 新压缩格式 + 编码器升级（`--compress`）

`--output-format` 新增 **avif / jxl**，且 JPEG/WebP 编码器全面升级：

| 格式 | 编码器 | 相比之前 |
|---|---|---|
| JPEG | jpegli（Google） | 同质量体积更小 |
| WebP | libwebp（wasm 转译） | **不再需要 CGO** |
| AVIF | libavif | 新增，AI 图通常比 JPEG 小 40-60% |
| JXL | libjxl | 新增 |

```bash
# 生成 AVIF，目标大小 500KB
aigc-cli image --prompt "猫" --compress 500KB -f avif

# 生成 JPEG-XL
aigc-cli image --prompt "猫" --compress 75% -f jxl

# 批量本地转 AVIF
aigc-cli image --compress 800KB -f avif -i a.png -i b.png
```

实测 41KB 测试图：jpg 6.7KB / webp 2.7KB / avif 3.0KB / jxl 4.4KB。

#### 下载格式嗅探

下载生成的图片时按**内容魔数**识别真实格式，修复了 API URL 缺扩展名或
带 query 参数导致保存成错误扩展名（如实际 WebP 存成 `.png`）的问题。

### ffmpeg 后处理速查文档

新增 [ffmpeg 常见命令速查](docs/zh/guide-ffmpeg.md)：配合 `video` / `audio`
命令的后处理（抽帧、缩略图、转 GIF、截取、转码、16k wav 转换等），
直接使用系统 ffmpeg，无需内置。

## Breaking Changes

- `chai2010/webp` CGO 依赖移除：WebP 编码不再需要 C 编译器（无 CGO 构建
  也支持 WebP 输出）
