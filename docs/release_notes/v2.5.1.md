# Release Notes v2.5.1

## New Features

### `depth --skeleton` / `--face` 支持视频（逐帧标注）

`depth` 命令的骨架/人脸标注从**仅图片**扩展为**图片 + 视频**：

```bash
# 图片标注（叠加在深度图上）
aigc-cli depth -i photo.jpg --skeleton        # 人体骨架（COCO17，19 骨骼 17 关节点）
aigc-cli depth -i photo.jpg --face            # 人脸：检测框 + 眼睛 + 15 点关键点

# 视频标注（逐帧检测并叠加到深度视频）
aigc-cli depth -i video.mp4 --face
aigc-cli depth -i video.mp4 --skeleton

# 模型准备
aigc-cli depth init --skeleton     # 下载 YOLOv8n-pose（13.5MB）
aigc-cli depth init --face         # 下载 pigo 人脸级联（~7.7MB）
```

- 视频标注复用深度转换的抽帧/编码管线，支持 `--start-time` / `--end-time` / `--keep-audio`
- 骨架/人脸可同时叠加：`--skeleton --face`

### 人脸检测引擎重构：ONNX → pigo（纯 Go）

`depth --face` 的人脸检测从 ONNX（BlazeFace + MediaPipe 468 点 + FER+ 表情）替换为
**pigo（纯 Go Pico 算法）**，修复了旧实现的检测框位置失真问题：

- **纯 Go 实现**，无 onnxruntime 运行时依赖，级联文件通过 `depth init --face` 下载
- 输出：人脸检测框 + 双眼（瞳孔）+ **15 点稀疏关键点**（眼区 10 + 嘴 4 + 鼻 1）
- **移除 FER+ 表情标签**（pigo 不支持，8 类表情分类不再输出）
- 提高大图检测召回：滑动窗口步长从 0.15 收紧到 0.10（修复 1024px+ 大图漏检）

### MCP `convert_depth` 工具支持 `annotate` 参数

MCP 工具 `convert_depth` 新增 `annotate` 参数，图片/视频均可叠加标注：

```json
convert_depth { "input_path": "/path/to/photo.jpg", "annotate": "skeleton" }
convert_depth { "input_path": "/path/to/video.mp4", "annotate": "face" }
convert_depth { "input_path": "/path/to/photo.jpg", "annotate": "skeleton,face" }
```

- 标注逻辑提取为 `internal/annotate` 共享包，CLI 与 MCP 复用同一实现

## Bug Fixes

- 修复 `depth --face` 在 1024px+ 大图上漏检人脸（pigo 窗口采样步长过粗）

## Breaking Changes

- **移除 FER+ 表情标签**：`depth --face` 不再输出 8 类表情分类（人脸框、眼睛、15 点关键点保留）
- **`depth init --face` 下载内容变更**：从 ONNX 模型（face_detector/landmark/emotion）改为 pigo 级联（facefinder/puploc/lp*）
