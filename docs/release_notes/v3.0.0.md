# Release Notes v3.0.0

## Highlights

### 🎵 全新的 `music` 音乐生成命令

`aigc-cli music` 用自然语言生成音乐，按 Provider 自动选择后端：

- **APIMart（默认）**：异步任务模型（提交 → 轮询 → 下载），`--model suno`（默认）或 `--model flowmusic`。
- **OpenRouter**：Google Lyria-3 同步流式（`google/lyria-3-clip-preview` / `google/lyria-3-pro-preview`）。

```bash
# 默认：APIMart suno
aigc-cli music generate --prompt "city pop, rainy night, female vocal"

# flowmusic 后端
aigc-cli music gen --prompt "upbeat rock with electric guitar" --model flowmusic

# OpenRouter Lyria-3（同步流式）
aigc-cli music gen --provider openrouter --model google/lyria-3-pro-preview --prompt "cinematic"

# 查询 / 续传异步任务（APIMart）
aigc-cli music query task_xxx
```

- `generate`（别名 `gen`）与 `query` 两个子命令
- 公共字段用 flag：`--prompt/--style/--title/--lyrics/--instrumental/--duration/--format`
- Provider 专属字段走 `--json`（如 suno 的 `style_weight`/`vocal_gender`、flowmusic 的 `bpm`/`seed`），最后合并、覆盖 flag 与代码默认值
- 生成结果自动下载到输出目录并打印 `Saved: <path>`
- `--dry-run` 打印等价 curl（APIMart / OpenRouter 各一套，host/key 取已解析的 Provider）
- 已接入 MCP 与 Chat Agent 的 `generate_music` 工具

> 注意：Suno 每次请求返回 2 个版本（CLI 会全部下载）；flowmusic 与 Lyria-3 每次返回 1 条。

## Other New Features

### `video --mp4`：本地媒体转 MP4

```bash
aigc-cli video --mp4 -i anim.gif     # GIF/WebP/MOV → MP4
aigc-cli video --mp4 -i clip.mov     # 保留源分辨率
```

- 通过 `-i/--image-url` 指定本地文件，纯本地执行（需 ffmpeg），不调用 API

### `chat --context-size`：上下文上限 + 自动压缩

```bash
aigc-cli chat --context-size 8192 --max-output 2048
```

- `--context-size` 设置最大输入上下文；超过 80% 时自动总结较早消息（与 `/compact` 同一套逻辑，交互式与非交互式均支持）
- `--max-tokens` 重命名为 `--max-output`
- 可通过配置 `defaults.context_size` 设置默认值
- 新增 nil-safe 配置访问器（`chatDefaults()` 等），替代手写长链 nil 判断
