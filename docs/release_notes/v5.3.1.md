# Release Notes v5.3.1

> 以「redact 支持 Word / PDF / 图片」为主的补丁版本。
> 同时合入 v5.3.0 之后的规则扩充、默认脱敏策略调整和 CLI 开关统一。

## Highlights

### 📄 Redact 支持 DOCX

```bash
aigc-cli redact apply 起诉状.docx --mapping 起诉状.map.json
aigc-cli redact restore 起诉状.redacted.docx --mapping 起诉状.map.json
```

- 与 TXT 共用 `style`：`placeholder` / `mask` / `black` / `hash`；
- 保留字体、表格、页眉页脚；
- 跨 run 的姓名/电话会合并识别后回填；
- `placeholder` 模式可生成 mapping 并还原；
- `check` 也可直接检查 DOCX 中的残留。

### 🧾 Redact 支持 PDF

```bash
aigc-cli redact scan 判决书.pdf --dpi 300
aigc-cli redact apply 判决书.pdf --dpi 300
```

- `--dpi` 默认 **300**；
- 有文字层的页面优先用文字层提取，扫描页自动 OCR；
- 输出为**纯图片 PDF**：页面渲染后按字符/词框画黑块，再重新生成 PDF；
- 不保留原文字层、注释、附件、JavaScript，复制输出 PDF 不会得到原文；
- 不做 overlay 覆盖层；
- PDF 不支持 `--mapping` / `restore`。

需要 `mutool`（mupdf-tools）渲染；OCR 需要先 `aigc-cli ocr init`。

### 🖼️ Redact 支持图片

```bash
aigc-cli redact scan 扫描件.png
aigc-cli redact apply 扫描件.png
```

- 自动 OCR，按字符/词框画黑块，只遮敏感片段，不整行涂黑；
- OCR 只能定位到整行时才整行兜底；
- 透明 PNG/WebP 铺白底并输出 JPEG；不透明图片保持原扩展名；
- JPEG quality 85，清除 EXIF/GPS；
- 图片不支持 `--mapping` / `restore`。

### 🎛️ CLI 自动识别格式

`redact apply` / `scan` 会按文件内容识别 `txt/md/csv/json/docx/pdf/image`，不再需要
`--pdf-mode`、`--ocr` 等模式参数。`--dpi` 仅用于 PDF。

支持矩阵：

| 格式 | apply | scan | check | restore / mapping |
|---|---|---|---|---|
| TXT / MD / CSV / JSON | ✅ | ✅ | ✅ | ✅（placeholder） |
| DOCX | ✅ | ✅ | ✅ | ✅（placeholder） |
| PDF | ✅ 栅格化黑块 | ✅ | ❌ | ❌ |
| 图片 | ✅ 黑块 | ✅ | ❌ | ❌ |

## 规则与默认策略

自 v5.3.0 起合入的脱敏增强：

- 新增凭据/密钥类规则：`password_assign`、`api_key_assign`、`authorization_header`、
  `bearer_token`、`cookie_header`、`api_key_known`、`jwt_token`、`private_key_block`、
  `db_url`、`url_with_credentials`、`ado_host`、`ado_username` 等；
- 新增法律文书规则：角色姓名、亲属姓名、`姓名：`、英文称谓姓名、机构全称/简称、
  作品名、税号、项目编号、加密钱包、IP；
- 身份证增加标签上下文和日期段宽松校验，虚构/校验位错误的号码也能识别；
- 模型识别的地址自动扩展到楼栋/单元/房间后缀；
- 日期、金额、民族改为**默认脱敏**；
- 姓名 mask 保留姓氏 + 固定一个 `*`（`张*` / `欧阳*`），不泄露名字长度；
- 民族固定 `*族` / `█族`；
- 日期统一 `****年**月**日` / `████年██月██日`，不泄露月日位数；
- `--only` / `--with-date` / `--with-amount` 统一为 `--enable` / `--disable`。

## 升级提示

- 无破坏性配置变更。
- PDF/图片输出不可逆；需要还原请使用 DOCX/TXT 的 `placeholder` 模式。
- PDF 输出页面是图片，不再可搜索/复制文字；这是为了避免保留原文字层。
- 需要 `mutool` 才能处理 PDF；需要 `aigc-cli ocr init` 才能处理图片/扫描 PDF。
- 设计文档已从 git 跟踪移除，改为本地 `docs/design/`。
