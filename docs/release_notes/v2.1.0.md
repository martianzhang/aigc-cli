# v2.1.0 — 本地知识库

## 新功能

### 知识库（knowledgebase / kb）

本地知识库引擎，支持全文检索和语义搜索。

**核心能力：**
- SQLite + FTS5 全文检索 + ONNX 语义搜索
- 项目隔离（自动按 git remote URL 归类）
- Web 搜索自动入库（DuckDuckGo / Brave / Firecrawl）
- 智能搜索降级：FTS5 → OR → 向量兜底

**CLI 命令：**
`init` / `add` / `fetch` / `map` / `find` / `search` / `list` / `show` / `rm` / `index` / `prune` / `reset`

**MCP / Chat 工具（6 个）：**
`kb_find` / `kb_search` / `kb_add` / `kb_fetch` / `kb_list` / `kb_show`

### 保险箱（Vault）

age 加密 + 系统钥匙串保护，加密内容可向量搜索：

`kb add --vault` / `kb fetch --vault` / `kb list --vault` / `kb show --vault` / `kb vault export/import`

### 搜索路由器

多搜索引擎自动 fallback，支持配额管理：

- DuckDuckGo（零配置）
- Brave Search API
- Firecrawl API

### 自定义加载器

通过配置文件定义外部命令处理 PDF/DOCX 等格式：

```yaml
defaults:
  knowledgebase:
    loaders:
      .pdf: "pdftotext $1 -"
```

## 技术

- ONNX 嵌入模型 `multilingual-e5-small`（384 维，跨语言）
- 纯 Go Unigram tokenizer
- CGO-optional：有 CGO → ONNX，无 CGO → HashEmbedder 降级
- 模型存储于共享目录 `~/.config/aigc-cli/models/`
- 新依赖：`filippo.io/age`、`github.com/zalando/go-keyring`
