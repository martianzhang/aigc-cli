# Release Notes v5.0.0

> 以「Provider 配置显式化」为主轴的破坏性版本：**移除内置 APIMart 默认 API 地址**，
> 未配置 `base_url` / provider 时命令直接报错，不再静默把请求发往某个厂商。
> 同时带来 `models` 目录接口纠偏、余额查询扩展、SoMark/OXR 文档解析与若干图片参数修复。
> **含 1 处不兼容变更**（见文末升级提示）。

## ⚠️ 破坏性变更

### 移除内置默认 API 地址

CLI 不再把 `https://api.apimart.ai` 作为兜底基址。`types.DefaultAPIBaseURL` 已删除，
`provider.ResolveCmdProvider` / `config.Load` / `client.NewWithProvider` 都不再补默认值。

- 未配置 `providers.<name>.base_url`、全局 `base_url`、`--api-base` 或 `OPENAI_BASE_URL`
  时，需要联网的命令会在发起请求前返回可操作的错误：

  ```text
  no API base URL for image: pass --api-base, set OPENAI_BASE_URL,
  or add base_url under providers.<name> in config.yaml
  ```

- Client 层新增统一守卫：空 base URL 不再变成相对路径 `/v1/...`，也不会出现
  `unsupported protocol scheme` 这类难懂错误。
- `config list` 在无配置文件时不再虚构一条 `base_url: https://api.apimart.ai`。
- 示例配置改为显式写出 `base_url`，并说明 CLI 没有内置默认地址。

受影响的命令包括 `image` / `video` / `chat` / `music` / `midjourney` / `audio speak|transcribe` /
`models` / `balance` / `task` / `decision`，以及 MCP 中需要联网的工具。纯本地命令
（`ocr` 本地模型、`detect`、`background`、`upscale` 等）不受影响。

## Highlights

### 🧭 models：`--type` / `--price` 只走真正支持的目录接口

`models --type` / `--price` 现在按解析后的 Provider 严格分派：

| Provider | 行为 |
|---|---|
| OpenRouter | 模型发现（全部输出模态）与单模型定价 |
| APIMart | marketplace 列表与定价 API |
| 其他（ModelScope、OpenAI、中转等） | 明确报错，不再静默查询 APIMart 市场 |

- marketplace / pricing 请求改用**当前 Provider 的 base URL**，不再读取全局 `api_base`。
- `models -P modelscope --type image` 会提示该 Provider 没有模型目录接口，并建议省略
  `--type` 直接列出其 `/v1/models`。
- 无 `--type` 的普通列表行为不变：仍查询 `GET /v1/models`。

### 🧠 models：默认 OpenRouter、`--like` 与完整模态

- 未显式选择 Provider 时优先使用已配置的 OpenRouter（模型 id 为 `author/slug`，
  且目录带分辨率、宽高比、参数范围等尺寸元数据）。
- 新增 `--like <text>`：按 id / 名称做大小写不敏感的模糊匹配；不带 `--type` 时跨全部模态。
- `--type` 覆盖 OpenRouter 的 `text`、`image`、`video`、`audio`、`speech`、
  `transcription`、`embeddings`、`rerank`、`decisions`、`all`，并支持
  `chat`/`llm`、`music`、`tts`、`stt`/`asr`、`embedding`/`embed` 等别名。
- image / video 发现继续使用专用端点以展示尺寸能力；查询价格时切回 `/models`。
- 修复 `--type chat` 误用媒体 schema、裸 `--price` 与 `--price <model>` 的路由。

### 💰 balance：OfoxAI 与 OpenAI 计费口径的中转

- 新增 OfoxAI 余额查询（`GET /v1/user/balance`，返回可用 / 累计入账 / 已用）。
- Provider 没有专属余额接口时按顺序探测：APIMart 风格 `/v1/balance`、`/v1/user/balance`，
  再尝试 OpenAI 兼容的 `/dashboard/billing/subscription` + `/usage`。
  new-api / one-api 系中转（aibase、agnes、openlux 等）可显示近 30 天已用金额；
  `hard_limit_usd` 为 `1000000` 占位值时视为“无额度上限”。
- 只有所有端点都失败时才显示 “not available”。

### 📄 ocr：SoMark / OXR 文档解析

- 新增 `type: somark` Provider，调用 `POST /parse/sync` 返回版面感知的 Markdown
  与结构化 JSON（含 bounding box、阅读顺序）。
- 支持 SoMark 正式版、免费 OXR（`https://free-oxr.somark.ai/api/v1`，无需 key）
  和自部署 OXR，只需替换 `base_url`。
- API 参数通过共享的 `--json` / `--inject-json` 传递；解析产生的远程图片会下载到
  `<name>.assets/` 并改写 Markdown 链接（SoMark 图片 30 天后失效）。
- 支持 zip 导出；被忽略的本地 OCR 参数（`--prompt` / `--model` / `--pages` 等）会明确提示。
- 余额查询支持剩余解析页数（付费页 + 今日/本月免费页）。

### 🖨️ ocr：`-o -` 与 `-m` 简写

- `-o -` 把识别结果打印到 stdout 并跳过 `.md` 文件，适用于管道：
  `aigc-cli ocr scan p.png -o - | pbcopy`。
- `--model` 新增 `-m` 简写（本地 flag 不再被根命令的持久 flag 遮蔽）。
- 补充请求驱动的 OCR 模型（如 `minicpm-ocr`）的 prompt 说明：不传 `-p` 可能得到
  “描述图片”而非文字识别结果。

### 🖼️ image：Gemini 尺寸映射与 OpenRouter 提示修复

- Gemini 原生分支现在支持像素尺寸、比例（`16:9`）、档位（`2K`）与组合
  `2K@16:9`，分别映射为 `aspect_ratio` + `image_size`；未知档位原样透传，
  由 API 自己报错。
- OpenRouter 的 `--size` 失败提示只列出模型实际声明的参数，不再对只有比例的模型
  建议 `2K@16:9` 组合；同时修复裸 `ratio` 误匹配 `generation` 导致所有失败都追加
  尺寸提示的问题。

## 行为变化

- 不再有“不配置就能跑”的默认 API 地址；所有联网命令都要求显式配置 Provider 或 base URL。
- `models --type` / `--price` 对没有目录接口的 Provider 直接报错。
- `models` 未指定 Provider 时优先使用 OpenRouter。
- `aigc-cli models --type image` 在未配置任何端点时不再默认查询 APIMart 市场。

## 升级提示

如果之前依赖内置 APIMart 地址，请在 `~/.config/aigc-cli/config.yaml` 中显式补上：

```yaml
# 方式一：全局 base_url（单 Provider 场景）
base_url: "https://api.apimart.ai"

# 方式二：命名 Provider（推荐，多 Provider 场景）
providers:
  apimart:
    api_key: "sk-xxx"
    base_url: "https://api.apimart.ai"
defaults:
  image:   { provider: apimart, model: "gpt-image-2-official" }
  video:   { provider: apimart, model: "doubao-seedance-2.0" }
  music:   { provider: apimart }
```

也可以临时用 `--api-base <url>` 或环境变量 `OPENAI_BASE_URL` 指定。

想列 ModelScope 等 Provider 的模型时，省略 `--type`：

```bash
aigc-cli models -P modelscope
aigc-cli models -P modelscope --like Qwen-Image
```
