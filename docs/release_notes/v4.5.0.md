# Release Notes v4.5.0

> 以「音效」为主轴的一次功能版本：新增 `audio sfx`（在线 + 本地 ONNX）、两个音频素材搜索 provider、MCP `generate_sfx`，并统一了本地推理的 provider 选择方式。**含 2 处不兼容变更**（见文末）。

## Highlights

### 🔊 新命令：`audio sfx`

短音效生成，专门解决「音乐模型一开口就是一首歌」的问题。时长、无缝 loop、prompt 贴合度都可控。

**在线（ElevenLabs / Stability）**

```bash
# ElevenLabs：0.5–30s，支持 loop 与 prompt influence
aigc-cli audio sfx -P elevenlabs -i "heavy metal door slam with echo" -d 1.5

# Stability：1–190s
aigc-cli audio sfx -P stability -i "rain on a car roof" -d 10
```

```yaml
providers:
  elevenlabs:
    base_url: https://api.elevenlabs.io
    api_key: "xi-xxx"
defaults:
  audio:
    sfx:
      provider: elevenlabs
      model: eleven_text_to_sound_v2   # 可换 eleven_text_to_sound_v3
      format: mp3
```

**本地（离线 ONNX）**

```bash
aigc-cli audio init --model stable-audio-open-small   # 约 507MB
aigc-cli audio sfx -P local -m stable-audio-open-small \
  -i "sci-fi UI confirmation beep" -d 0.8 --seed 42
```

- Stable Audio Open Small（341M，44.1kHz 立体声，最长 11.9s），纯 Go + ONNX Runtime，无 Python、无 CGO；
- 8 步 rectified-flow pingpong 采样，输出峰值默认归一化到 -1 dBFS，`--no-normalize` 可保留原始电平；
- 同 `--seed` 结果可复现；
- 模型来自 `aigc-cli-models` release，下载时逐个校验 SHA-256，并附带 LICENSE / NOTICE。

### 🔍 `search`：新增音效素材 provider

```bash
# SFXMint：免 API key，全 CC0，结果直接带 WAV/MP3 直链
aigc-cli search -P sfxmint "door slam" -n 5

# Freesound：需要免费 API key；用厂商 filter 只要 CC0、限定 3 秒内
aigc-cli search -P freesound "whoosh" -n 5 \
  --inject-json '{"filter":"license:\"Creative Commons 0\" duration:[0 TO 3]"}'
```

- 两个 provider 都只透传厂商原始 JSON，不额外增加 `--license` / `--duration` 参数，过滤统一走 `--inject-json`；
- `--list-providers` 的 MEDIA 列会显示 `sfx`；
- Freesound 原档下载需要 OAuth2，CLI 返回公开预览 MP3；SFXMint 直接返回 WAV/MP3。

### 🤖 MCP：新增 `generate_sfx` 工具

Agent 现在可以直接生成音效，参数与 CLI 对齐（`input` / `duration` / `loop` / `influence` / `format` / `seed` / `normalize`），`provider=local` 时走离线模型。

```jsonc
{ "input": "heavy metal door slam", "duration": 1.5, "provider": "local", "seed": 42 }
```

### 🔁 本地推理统一为 `-P local`

`audio speak` / `transcribe` / `sfx` 不再有专用 `--local` 参数，改为和其它命令一致的内置 provider：

```bash
aigc-cli audio speak -P local -m kokoro -i "你好"
aigc-cli audio transcribe -P local -m sense-voice -i recording.wav
aigc-cli audio sfx -P local -m stable-audio-open-small -i "door slam"
```

也可以写进配置，省掉 `-P local`：

```yaml
defaults:
  audio:
    speak:
      provider: local
      model: kokoro
    transcribe:
      provider: local
      model: sense-voice
    sfx:
      provider: local
```

## 不兼容变更

### 1. `defaults.audio` 改为分节结构

旧版扁平键**不再读取**，请迁移到 `speak` / `transcribe` / `sfx` 子节：

```yaml
# 旧（v4.4 及之前）
defaults:
  audio:
    format: wav
    speak_model: kokoro
    transcribe_model: sense-voice
    voice: zf_xiaoxiao

# 新（v4.5）
defaults:
  audio:
    speak:
      model: kokoro
      voice: zf_xiaoxiao
      format: wav
    transcribe:
      model: sense-voice
```

同时删除了 `defaults.audio.provider`（共享兜底）。每个子命令各自解析 provider：
`-P/--provider` > `defaults.audio.{speak|transcribe|sfx}.provider` > 全局 > 内置默认。

### 2. 移除 `audio speak/transcribe/sfx --local`

改用 `-P local`（或配置 `provider: local`）。本地模型仍由 `-m` 指定。

## 升级提示

- 本地音效需要先下载模型：`aigc-cli audio init --model stable-audio-open-small`；
- 旧配置不会报错，但扁平键会被忽略——升级后请检查 `aigc-cli --print-config` 里的 `defaults.audio`；
- 模型资产名 `sfx-sao-small-*` 视为 ABI：后续若引擎/张量变更，会发布新的 `-vN-` 前缀，不覆盖旧文件。
