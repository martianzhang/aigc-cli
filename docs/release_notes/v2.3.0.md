# Release Notes v2.3.0

## New Features

### Crop Watermark (`--crop-watermark`)
Generic watermark removal via image cropping - no learning required.

```bash
# Auto mode: detect watermark and crop
aigc-cli detect image.png --crop-watermark auto

# Keep percentage of edge length
aigc-cli detect image.png --crop-watermark 97%

# Crop to target dimensions
aigc-cli detect image.png --crop-watermark 1920x1080
```

- Automatically detects watermark regions in image corners
- Falls back to 5% margin if no watermark detected
- Maximum 20% crop ratio to prevent excessive cropping

### MCP Tools

#### `get_config`
Get current effective configuration with API keys masked.

#### `crop_watermark`
Crop-based watermark removal via MCP, supporting auto/target/percentage modes.

## Bug Fixes

### PNG EXIF TC260 Detection
- Added support for `eXIf` chunk in PNG files
- Fixed TC260 AIGC label detection from PNG EXIF data

### API Key Masking
- `--print-config` now masks API keys in `providers` and `web_search` sections
- MCP `get_config` tool also masks all API keys
