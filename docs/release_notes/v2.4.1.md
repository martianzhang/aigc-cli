# Release Notes v2.4.1

## New Features

### 视频深度转换 `video --convert-to-depth`

把普通视频转成**灰度深度视频**（近亮远暗、保留动作与空间结构、去除纹理）。
这是深度引导 / 控制视频式图生视频（Wan VACE、Kling 动作控制、Vidu 参考生视频）
的标准输入：上传深度视频 + 参考照片，AI 即可生成"保留原动作、换成新外观"的视频。

```bash
# 首次使用：安装 ONNX Runtime + 深度模型（默认 depth-anything-v2-small，Apache-2.0）
aigc-cli video init

# 转换整个视频（输出 <input>_depth.mp4，H.264 灰度）
aigc-cli video --convert-to-depth -i input.mp4

# 只转前 5 秒（先用小段调参，满意后再全量）
aigc-cli video --convert-to-depth -i input.mp4 --end-time 5

# 指定时间区间 / 模型 / 分辨率
aigc-cli video --convert-to-depth -i input.mp4 --start-time 00:01:00 --end-time 00:01:30
aigc-cli video --convert-to-depth -i input.mp4 --depth-model depth-anything-v2-base --depth-size 378

# 只打印要执行的 ffmpeg 命令，不实际转换
aigc-cli video --convert-to-depth -i input.mp4 --dry-run
```

- 深度估计完全**本地 ONNX 推理**（Depth Anything V2），无需 API Key、无需联网
- 默认推理分辨率 280（14 对齐），Apple Silicon 上 1 秒 24fps 视频约 5 秒内完成；
  `--depth-size 378/518` 可换取更高质量
- 保留原视频**宽高比**（等比缩放 + pad-crop），横屏/竖屏均正确
- 支持 `--invert`（近暗远亮）、`--no-smooth`（关时序平滑）、`--keep-audio`（保留音轨）
- ffmpeg 缺失时打印各平台安装建议，不自动捆绑

### 新 MCP / Chat 工具 `convert_video_depth`

`convert_video_depth` 同时注册为 MCP 工具和 Chat Agent 工具（离线、免 API Key），
AI 代理可直接把视频转成深度视频供下游深度引导工作流使用。
已在 `tools_enable` 白名单示例中补充（本地 config 同步更新）。

## Performance

- **内存修复**：修复 ORT（onnxruntime ≥1.26）在 arm64 上 KleidiAI GEMM 后端每次推理
  泄漏 ~6MB 工作缓冲的问题（禁用该后端，100 帧转换内存从 ~2.6GB 降至 ~360MB）
- **速度优化**：推理线程数限制 + 默认 280 分辨率，1 秒视频从 ~20s 降至 ~5s

## Bug Fixes

- 深度视频**比例失真**：修复等比缩放 pad 后把含黑边的方形输出直接拉伸回原尺寸、
  导致内容比例改变的问题（pad-crop 机制）
- 单帧解码失败时不再把彩色帧混入灰度输出（跳过并删除源帧）
