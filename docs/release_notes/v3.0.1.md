# Release Notes v3.0.1

## Bug Fixes

### flowmusic 生成在轮询阶段失败（`duration` 解析）

flowmusic 的 `POST /v1/music/generations` 任务结果里，`result.music[].duration` 返回的是**带引号的数字字符串**（如 `"181.7"`），而 CLI 之前用 `float64` 解析，导致提交成功、轮询到一半直接报错：

```
json: cannot unmarshal string into Go struct field
MusicTrack.data.result.music.duration of type float64
```

修复：

- 新增 `types.FlexFloat`：同时接受 JSON 数字或数字字符串，`MusicTrack.Duration` 改用它
- 补回归测试 `TestMusicTaskResponse_flexibleDuration`

```bash
# flowmusic 现在可正常生成
aigc-cli music generate --model flowmusic --prompt "upbeat pop with piano" --duration 60

# 若任务已在服务端完成，可用 query 续取并下载
aigc-cli music query <task-id>
```

> 注：Suno（`duration` 为数字）与 OpenRouter Lyria-3 不受影响。

## Security

- `--dry-run` 统一对 API Key 脱敏（`maskKey`，仅保留后 4 位）：本次覆盖 `music` / `image` / `midjourney` / `video`（`audio` 原本已脱敏）
