# Release Notes v2.6.1

## Bug Fixes

### `--crop-margin` 精确裁切（不再误裁左右）

修复 `--crop-margin 64,0` 只裁上下时，画面左右被意外裁掉的问题。之前的"保持原始宽高比"步骤会放大画面并居中裁切，导致 0 也变成非 0。

```bash
# 现在：只裁上下 64px，左右保持不动
aigc-cli video --gif -i org.mp4 --crop-margin 64,0
```

- 改为精确按指定边裁切，不做任何恢复原比例的额外缩放裁切
- 文档和 `--help` 同步更新

### MCP `generate_video` 支持 GIF + agnès

MCP 的 `generate_video` 工具之前只提交任务返回 task_id（不下载不转 GIF），且不支持 agnès。

- 新增 `gif`、`gif_width`、`crop_margin` 参数
- 完整同步执行：提交 → 轮询 → 下载 →（可选）转 GIF，返回实际文件路径
- 新增 agnès 视频分支（`POST /v1/videos` → `GET /agnesapi` 轮询）
- 修复 MCP `shared.Cfg` 缺失导致命名 provider（`defaults.{cmd}.provider`）不生效的 bug

### agnès 图生视频

agnès 没有图片上传端点，之前调上传接口会 404。

- 本地图片自动转为 base64 data URI 内嵌（无需上传）
- 修正 agnès 视频模式：`text`/`keyframe`/`reference`（之前用了不存在的 `image2video`）
- 图片放 `images[]` 数组，补 `aspect_ratio` 参数

```bash
# 图生视频：本地图片自动转 data URI
aigc-cli video -i photo.jpg --prompt "让照片中的人动起来" --gif
```

### agnès 文生图兼容

- 清空 agnès 不支持的 `quality` 和 `output_format` 参数（之前报 400）
