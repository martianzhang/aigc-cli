# Release Notes v3.7.0

> 新增 `decision` 命令：把 System One / 决策模型接入 CLI。给一段文本 + 一套"题库"，返回**带校准概率的结构化决策**（选择 / 是非 / 评分）——JSON 输出、可直接管道。既支持本地 Ollama（`tev1`/`nimble`，离线零成本），也支持在线 OpenRouter（`typesafe/jev-*`）等。本版另新增 `defaults.decision` 配置与示例题库。

## Highlights

### 🧮 新命令 `aigc-cli decision`（别名 `decide` / `systemone`）

决策模型不生成文本，而是在一次前向里回答**类型化问题**并返回校准概率。三种问题原语：

| 类型 | 含义 | 返回 |
|---|---|---|
| `choice` | 从 2–24 个选项里选一个 | 选中项 + 每项概率 + `confidence` |
| `noul` | 是非判断 | 答案为"是"的概率（0–1） |
| `score` | 有序打分 | 概率加权档位 + 各档分布 + `confidence` |

题库驱动，调用方只给素材：

```bash
# 本地 Ollama（免费、离线）；题库与素材都是文件
aigc-cli decision --json triage.json --questions intent,refund --state state.txt

# 切到 OpenRouter 上的远程 Jev 模型
aigc-cli decision -P openrouter -m typesafe/jev-latest --questions intent --state state.txt

# 结构化素材（给模型分区的语义）
aigc-cli decision --questions refund \
  --state '{"policy":"Refunds within 30 days.","request":"Bought 12 days ago, want a refund."}'
```

- **题库**：`--json <file|inline-json|->`（JSON/JSONC，1–64 个命名问题，含 `type`/`instructions`/`criteria`，可选默认 `model`/`state`）。
- **选题**：`--questions a,b,c`（逗号分隔/可重复，缺省=全部）。
- **素材**：`--state <text|file|->`（`-` 读 stdin；内容是合法 JSON 对象/数组则按结构化发送）。
- **JSON 输出**：默认即 JSON，直接 `jq`。例如只在模型确信时采用：
  ```bash
  aigc-cli decision --json triage.json --state state.txt \
    | jq -r 'if .answers.intent.confidence > 0.85 then .answers.intent.choice else "ESCALATE" end'
  ```
- **provider/model 切换**：复用全局 `-P/--provider`、`-m/--model`。
- **端点按 provider 自动归一化**（各厂商路径不同）：Ollama `…/v1/systemone`、OpenRouter `…/api/v1/systemone`、TypeSafe、LLM Gateway、LiteLLM 代理。
- **诊断**：`--list` 列出题库中的问题名；`--dry-run` 打印等价 curl（零成本）。

### ⚙️ 新增 `defaults.decision` 配置

```yaml
defaults:
  decision:
    provider: ollama            # config.providers 里的命名 provider（ollama / openrouter / ...）
    model: tev1                 # tev1 | tev1:0.8b | nimble | typesafe/jev-latest
    bank: ~/exams/triage.json   # 默认题库（--json 缺省时使用）
```

优先级：`CLI 参数 > 题库 JSON > defaults.decision > 代码默认值`。

## 兼容性说明

- **纯新增，无破坏性变更**：不改动既有命令行为，不新增第三方依赖。
- **本地运行需 Ollama ≥ 0.35.0**（决策模型走 `/v1/systemone`，0.35.0 起支持）。
- **注意**：`confidence` 表示概率分布的集中程度，**不是**答案正确的概率；决策模型可能出错，官方也建议不要作为高风险决策的唯一依据。若没有合适选项，请在题库里显式加 `none`/`other`。
