# Release Notes v5.4.2

> 以「稳定性、安全加固与工程护栏」为主的补丁版本，无破坏性变更。
> 长任务可取消、下载与模型安装更可靠、错误信息不再泄露密钥，
> 并补上了跨平台 lint、race、覆盖率门槛、fuzz 与发布校验。

## Highlights

### 🛡️ 下载与网络加固

- `FetchBytes` 增加状态码检查、超时与大小上限；媒体下载改为单次嗅探扩展名，
  不再为了判断类型重复下载同一文件。
- 新增 SSRF 防护：知识库抓取、网页抓取和媒体下载都会校验目标地址与每一次重定向，
  拒绝私网、链路本地和云元数据地址；媒体下载保留回环地址，本地 provider
  （Ollama / LocalAI）仍可正常工作。
- 安全请求（GET/HEAD）增加带抖动的重试，并尊重服务端返回的 `Retry-After`。
- 聊天流式输出按 40ms 合并增量后再渲染，降低长回复的终端刷新压力；
  主要 API 响应体统一设置 32 MiB 上限。

### 🔐 错误信息与依赖安全

- 上游错误体截断到 2 KB，并对 URL query token、JSON `api_key` / `token`、
  `Bearer` 值和 `sk-` 前缀密钥统一脱敏，避免调试输出把凭据带到终端或日志。
- 剩余 `io.ReadAll` 调用全部加上限或说明，`make lint` 与 CI 增加对应门禁。
- 升级 `x/net`、`x/image`、`x/text`，`govulncheck` 为 0 漏洞。

### 📦 模型安装可续传、可校验

- `vision` / `depth` / `upscale` / `detect` / `background` / `ocr` / `redact` /
  `ideas` 的模型安装统一走 `modelstore`：Range 续传、原子写入、SHA256 校验。
- 对上游尚未发布摘要的模型采用 TOFU（首次信任）：首次安装写入
  `<model>.sha256`，后续安装校验同一文件；已发布摘要的模型仍以官方值为准。

### ⏹️ 可取消的长任务

- 根命令接入信号上下文，HTTP 请求、异步任务轮询、知识库抓取等都会响应 `Ctrl-C`，
  不再需要等超时或强杀进程。
- 图片解码增加 100 MP 上限，避免超大图或解码炸弹占满内存。

### 🖼️ 体验修复

- `image` 新增 `-n/--number`（旧 `--n` 保留为隐藏别名）；ModelScope 异步请求会
  转发 `n`，返回数量不足时给出明确警告。
- iTerm2 内联预览改为按图片自身像素矩形预留区域，修复底部黑带与 HiDPI 下的
  尺寸偏差。
- 启动更轻：主密钥改为懒加载，`version` / `__complete` 不再等待 1 秒 keyring 超时。

## 工程与 CI

- CI 新增 race job；覆盖率门槛设为 50%（`-short`，不依赖本地模型/ffmpeg）；
  增加 benchmark smoke；发布资产附带每平台 `SHA256SUMS` 与 `go version -m` SBOM。
- lint 启用 `bodyclose`、`noctx`、`gocritic`、`gosec`；darwin / linux / windows
  三平台均为 0 issues。
- 新增 6 个 fuzz 目标（jsonmerge / reqbuild / redact / argutil / session / webfetch），
  均已完成基线运行；`reqbuild` 保留了一个 NUL method 回归语料。
- 新增 `internal/testutil`，dry-run 契约测试统一使用零网络断言。
- `internal/mcp` 不再依赖 `internal/cli`；MCP 工具目录改由注册表生成。
- 删除静态 `docs/reference/cli-reference.md`，`--help` 作为命令参考的唯一来源。

## 升级提示

- 无破坏性变更，直接覆盖二进制即可。
- 如果脚本曾读取 `docs/reference/cli-reference.md`，请改用
  `aigc-cli <command> --help`。
- 首次安装未发布摘要的模型时会生成 `<model>.sha256`；请勿删除该文件，
  否则下次安装会重新走首次信任流程。
- 使用本地 TTS / ASR 的用户仍建议解压完整发布包，保持二进制与原生库在同一目录。

## 验证

- `make test`、`go test -race ./... -short`、`go vet ./...`、`make lint` 全部通过；
- `golangci-lint` 在 darwin / linux / windows 三平台均为 0 issues；
- `govulncheck` 0 漏洞；`make cover-check` 57.9%（门槛 50%）；
- 6 个 fuzz 目标全部 PASS，累计执行数亿次输入。
