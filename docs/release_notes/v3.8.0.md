# Release Notes v3.8.0

> 本版聚焦**本地模型能力扩展**：`decision` 支持多模态图片（Clef / Clef-Flash）；知识库与灵感检索的 **embedding 后端可插拔**（内置 ONNX / 本地 Ollama / 在线 OpenAI 兼容）；新增 **`ideas` 语义检索**（BM25 + 向量 RRF）。另修复若干问题并增强图片处理稳健性。

## Highlights

### 🖼️ `decision` 支持多模态图片（Clef / Clef-Flash）

决策模型现在可以判定图片，与文本 `state` 一起联合评分（System One 的 `images` 字段，raw base64）：

```bash
# 本地 Ollama ≥ 0.35.1 + clef-flash
aigc-cli decision -m clef-flash --image form.png \
  --questions complete,type --state "The agent wants to submit the attached form."
```

- `--image <path|data-uri>`：可重复；本地 PNG/JPEG/WebP 自动编码，`data:` URI 自动剥离；URL 拒绝（API 不支持）。
- `--image-resize <px>`：默认 1024，`0` 关闭。**像素尺寸决定视觉 token 与耗时**——2848×1600 约 4000 token / 45s，缩到 1024px 约 800 token / 6s；只缩最长边、保持宽高比、永不放大。
- 图片按**位置**共享给全部问题；纯文本模型（如 tev1）仍照常工作。

### 🔌 可插拔 embedding 后端（knowledgebase + ideas）

语义检索的 embedding 后端不再写死。配置 `embedding_provider` + `embedding_model`：

| `embedding_provider` | 后端 |
|---|---|
| 留空 / `local` / `onnx` | 内置 ONNX E5（无 ONNX 时降级为纯 Go hash） |
| `hash` | 纯 Go n-gram 哈希（无模型，质量低） |
| `config.providers` 里的任意名字 | OpenAI 兼容 `/v1/embeddings`——**本地 Ollama 或在线厂商通用** |

```yaml
defaults:
  knowledgebase:
    embedding_provider: ollama
    embedding_model: embeddinggemma-2:270m   # 纯文本小模型（378MB）；:570m 更高质量
    embedding_timeout: 180
```

- `Embedding` 由 `[384]float32` 泛化为 `[]float32`，支持任意维度（如 embeddinggemma-2 = 768）。
- **修复**：此前入库用 Hash、检索用 ONNX 的**向量空间不一致**（统一到同一后端）。
- 存储 embedder 指纹，后端变更时提示重建索引。

### 🔍 `ideas` 语义检索（BM25 + 向量 RRF）

配置 `defaults.ideas.embedding_provider/embedding_model` 即启用；未配置则保持纯关键词（向后兼容）。

```yaml
defaults:
  ideas:
    embedding_provider: ollama
    embedding_model: embeddinggemma-2:270m
    embedding_timeout: 180     # 单次请求超时秒数（默认 180）
    embedding_max_runes: 256   # 入库文本截断长度（默认 256；越小越快）
    semantic_top_k: 200        # 语义召回参与 RRF 的条数（默认 200）
```

- **向量缓存**：`ideas_emb_<model>_<dim>.bin`（含模型 + 维度 + 数据集指纹），首次构建一次、之后秒回；换模型/改配置自动重建。
- 输出新增元信息行：`Source: local · Retrieval: BM25 + semantic · Model: embeddinggemma-2:270m`。
- 实测效果（29K 提示词库）：中文 query「赛博朋克夜景」关键词 **0** 命中 → 语义 **200** 命中（跨语言）；"cute pet sleeping" 3 → 202。

### 🛠️ 图片稳健性 & 修复

- **不再崩溃**：`validateLocalImage` 用 recover 兜住 jpegli 解码器在部分合法 progressive JPEG 上的 panic，回退魔术字节校验。
- 修复 `min_score: 0` 被忽略的问题——现在真正关闭相似度过滤。
- 修复 OpenRouter 视频生成 / 下载链路与媒体模型发现。

## 配置位置说明

- `defaults.ideas`（与 `knowledgebase` 对齐）。若你曾配置**顶层** `ideas:`（如 `data_path`），请移到 `defaults.ideas:` 下。

## 验证

- `make fmt` / `make build` / `make test` / `make lint`（0 issues）全部通过。
- 本机 Ollama 实测：`decision` 多模态（clef-flash）、`embeddinggemma-2:270m` / `:570m` 的 KB 与 ideas 语义检索端到端。
- 新增测试：可插拔 embedder 选择、API embedder（httptest）、向量缓存指纹、语义排序、decision 图片解析/缩放。

## 兼容性说明

- **无破坏性变更**：未配置 `embedding_provider` 时行为与旧版一致（KB 用内置 embedder、ideas 纯关键词）。
- 多模态决策需 **Ollama ≥ 0.35.1**（Clef / Clef-Flash）；`embeddinggemma-2` 为纯文本 embedding 模型。
- 首次启用 ideas 语义检索需为数据集预计算向量（29K 条约 9 分钟，一次性；之后走缓存）。
