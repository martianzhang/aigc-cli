# Release Notes v5.3.0

> 以「redact 离线 PII 脱敏」为主的次版本。
> 同时包含 Chat 会话切换/保存、bash 超时配置、2026 模型上下文窗口刷新，
> 以及 MCP / 网络超时相关修复。

## Highlights

### 🔒 Redact：纯文本离线脱敏

新增完整的 `aigc-cli redact` 命令树：

```bash
aigc-cli redact scan 起诉状.txt
aigc-cli redact apply 起诉状.txt --mapping 起诉状.map.json
aigc-cli redact check 起诉状.redacted.txt --mapping 起诉状.map.json
aigc-cli redact restore 起诉状.redacted.txt --mapping 起诉状.map.json
aigc-cli redact rules
```

- **默认零网络**：40 条内置规则 + 校验位（身份证、手机、银行卡、邮箱、统一社会信用代码、
  案号、合同号、车牌、护照、律师执业证号等），不配置模型也能用；
- **规则控制**：`rules` 开关、`overrides`、自定义正则、`allow` / `deny`、
  别名归并、精确词表、`dictionary_files`（TSV/CSV/JSON）；
- **替换风格**：`placeholder` / `mask` / `black` / `hash`，内置类型自带合理掩码策略；
- **可逆映射**：`apply --mapping` 生成映射，`restore` 还原；支持 `--encrypt` 加密映射；
- **残留检查**：`check` 发现残留时返回退出码 2，可直接用于 CI；
- **人工复核**：`scan --json` 输出 span，人工调整后 `apply --spans` 应用；
- **外部配置/profile**：`defaults.redact.config_file`、`profiles`、`--profile`、
  `--redact-config`，规则集可以独立成文件、按案件/团队切换；
- **MCP 工具**：新增只读 `redact_text` 与 `redact_check`。

#### 模型后端

- `--engine rules|model|auto` 控制检测流程；
- `--model-engine auto|chatner|tokencls` 控制模型适配器；
- Ollama / OpenAI 兼容模型走 `chatner`，本地 ONNX 走 `tokencls`；
- 模型名统一走 `--model`（或 `defaults.redact.model`），不要写进 `--model-engine`；
- 显式指定 `--provider ollama` 时 `auto` 自动选择 `chatner`；
- 本地 ONNX 模型支持 BIO/BIOES + 约束 Viterbi，并加入 `high_recall` 转移偏置，
  长句里的人名/地址不再因单个 token 置信度不足而漏检。

#### 本地 ONNX 模型下载

```bash
aigc-cli redact init --list
aigc-cli redact init --model zh-pii
```

- 模型：**privyscope-zh-hans 0.1.7**（简体中文 PII token classifier）；
- 上游：<https://github.com/zafrem/privyscope-zh-hans>；
- 许可：**Apache-2.0**；
- 下载源：`https://github.com/martianzhang/aigc-cli-models/releases/tag/v1`；
- 逐文件 SHA256 校验，安装 `LICENSE.txt` / `NOTICE.txt`，`--force` 才覆盖已有文件。

### 💬 Chat：会话切换、保存与列表

- 新增 `/session` / `/sessions` / `/resume`，可在 TUI 内列出并切换会话；
- 新增 `/save` 保存当前未落盘会话，`/session find <关键词>` 搜索全部会话；
- 新增 `--list-sessions` 与 `--session-limit`（默认最近 20 条，0 = 全部）；
- 切换会话会恢复历史、system prompt、provider/model、上下文窗口，并重置工具授权；
- 退出时关闭当前切换后的会话。

### 🧠 Chat：2026 模型上下文窗口

- 内置窗口表更新为主流 2026 模型家族（>=128K）；
- 移除已下线的 `gpt-5.5` / `glm-5` 和过短的 `o1` / `o3` / `o4` 前缀；
- 支持最长家族前缀匹配、`-128k` / `-1m` 后缀、provider 前缀与 `:variant` 归一；
- 保持 `/models` 探测与 `fallback_context_window` 兜底。

### ⏱️ Chat：bash 超时可配置

- 新增 `defaults.chat.bash.timeout`（秒，默认 300）；
- `bash` 工具支持可选 `timeout` 参数（秒，最大 86400）；
- 优先级：工具参数 > 配置 > 300s；
- 超时/Ctrl+C 会杀掉整个进程组，并返回可操作的错误信息；
- `!command` 改为后台执行，TUI 保持响应，Esc/Ctrl+C 可取消。

### 🌐 网络与 MCP 修复

- `--timeout` / 全局 `timeout` 现在覆盖搜索、chat/MCP fetch/Web 搜索、KB 文档抓取和
  MCP 启动握手（未配置时兜底 30s，握手上限 60s）；
- MCP 生成类工具按当次调用的 `provider` 选择端点、API key、模型和本地模型目录；
- 图片响应缺少 `created` 时使用毫秒时间戳命名，避免反复覆盖 `image_sync_0_0.png`；
- Chat 上下文占用显示保留小数百分比；
- 异步任务轮询间隔统一为 5s。

### 🖼️ Preview：`--preview` 不再把 base64 打到屏幕上

`--preview` / `aigc-cli preview` 在 iTerm2 / Kitty / Sixel 终端里是往 `stdout` 写
OSC 1337 / Sixel 转义序列内联渲染图片的，旧实现有两个问题：不管 `stdout` 是不是终端都照写
（管道、重定向、IDE/TUI 捕获时整段 base64 被当普通文本打印），且 payload 是原图字节
（1.4 MB PNG → 1.87 M 字符）。现在：

- **只在 `stdout` 是真实终端时内联渲染**，否则一律交给系统看图器；
- **payload 变成预览副本**：超出终端预算或 512 KB 时先缩放再重编码（不透明转 JPEG、
  带透明度转 PNG），1.4 MB PNG 的转义从 1.87 MB 降到约 17 KB；
- 超过 512 KB 上限（如超大 GIF）直接退回系统看图器，不再赌终端能吞下整条转义序列；
- GIF 仍原样发送，保留动画；
- 新增 `AIGC_CLI_NO_INLINE_PREVIEW=1` 完全关闭内联渲染，与 `AIGC_CLI_NO_TITLE` 行为对齐。

### 🖥️ 终端表格对齐

新增共享的宽度感知表格渲染：

- CJK/emoji 按两列计算，ANSI 颜色序列不计宽；
- `redact scan/check/rules`、`kb list`、`models --list-providers`、Web provider 列表统一使用；
- 混合中英文的 TYPE/TEXT/RULE/POS 等列不再错位。

## 升级提示

- 无破坏性变更；不配置 `redact` 时其他命令行为不变。
- `--preview` 的图片不再内联渲染到管道/日志：需要终端内联请直接在真实终端运行；
  只想用系统看图器可设 `AIGC_CLI_NO_INLINE_PREVIEW=1`。
- `redact` 默认只跑规则；需要模型时显式加 `--engine auto`。
- 模型名用 `--model has4`，`--model-engine` 只接受 `auto` / `chatner` / `tokencls`。
- 本地 ONNX 模型首次使用前运行 `aigc-cli redact init --model zh-pii`。
- Chat 会话切换不会修改已有会话文件；`--list-sessions` 为只读操作。
