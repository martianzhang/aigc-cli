# v2.2.0 — Agnes 独立 Provider + 图片压缩输出路径

## 新功能

### Agnes 独立 Provider
- 新增 `Agnes` 作为独立 Provider 类型，自动检测 `agnes-ai.com` 域名
- 专用 `runAgnesImage` 运行器，正确处理 Agnes API 差异：
  - `image_urls` → `extra_body.image`（图生图）
  - `response_format` → `extra_body.response_format`
  - 支持 `ratio` 参数（Agnes 2.1 Flash 档位式尺寸：`1K`/`2K`/`3K`/`4K` + `16:9`/`1:1` 等）
- CLI 新增 `--ratio` 标志
- MCP `generate_image` 工具新增 `ratio` 参数和 Agnes 处理分支

### 图片压缩输出路径
- `--compress` 处理后现在同时打印压缩后的文件名

## 技术变更

- `internal/provider/detect.go`: 新增 `Agnes` 类型、域名匹配、`IsAgnes()` 函数
- `internal/types/types.go`: `GenerateRequest` 新增 `Ratio` 字段
- `cmd/image_runners.go`: 新增 `runAgnesImage`
- `cmd/image_dispatch.go`: 策略表新增 Agnes 条目
- `internal/mcp/tools_generate.go`: 新增 `handleMCPAgnesImage`
