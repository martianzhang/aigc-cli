# Release Notes v4.7.0

> 以「chat 会话」为主轴的一次功能版本：新增 JSONL 会话保存 / 恢复 / 命名，
> 聊天记录可以跨进程继续；同时带来 TUI 拖拽复制、流式输出期间继续编辑草稿、
> 拒绝工具调用并给模型建议、`models` 支持 OpenRouter 全部模型类型等改进。

## Highlights

### 💾 chat：JSONL 会话保存、恢复与命名

聊天默认仍然不落盘。现在可以显式保存，并在之后继续同一次会话：

```bash
# 新建会话（自动生成 session id）
aigc-cli chat --save

# 命名新会话
aigc-cli chat --save --name "review auth"

# 按 id 恢复（在 ~/.config/aigc-cli/sessions/ 中查找）
aigc-cli chat --session 20261028T032236Z-a49cdc6c

# 按文件恢复；文件不存在时在该路径新建
aigc-cli chat --session ./logs/review.jsonl

# 恢复时改名
aigc-cli chat --session 20261028T032236Z-a49cdc6c --name "review auth v2"
```

- 默认目录 `~/.config/aigc-cli/sessions/`，文件权限 `0600`、目录 `0700`；
  可用 `--session-dir` / `defaults.chat.session_dir` 覆盖。
- `--session` 传 id 时只在会话目录查找，id 不存在直接报错；传路径时文件不存在会在该路径新建。
- 会话文件是追加式 JSONL：`header` / `system` / `message` / `compaction` /
  `clear` / `session_info` / `end`。
- system prompt（含 AGENTS.md）随会话保存；恢复时使用当时保存的版本。
- 图片附件只保存元数据（文件名、MIME、字节数），不保存 base64。
- 工具输出单条默认最多 32 KiB，超出部分截断并标记；可用
  `defaults.chat.session_tool_output_max_bytes` 调整。
- `/compact` 和自动压缩不会删除旧消息，只追加 `compaction` 记录。恢复时模型只看
  「最新摘要 + 压缩点之后的消息」，所以 session 文件再大也不会把完整历史塞进上下文。
- 未显式指定 `--context-size` 时，恢复沿用会话创建时记录的值；恢复后的投影仍超限会在
  首次请求前自动压缩一次。
- `/clear` 写入 `clear` 屏障，恢复时不会把清空前的消息带回来。
- 新建会话退出时打印路径、名字和可直接执行的恢复命令（自定义目录会带上
  `--session-dir`）：

  ```text
  Session: /Users/you/.config/aigc-cli/sessions/20261028T032236Z-a49cdc6c.jsonl
  Name:    review auth
  Resume:  aigc-cli chat --session 20261028T032236Z-a49cdc6c
  ```

### 🏷️ 会话命名与 banner

- `--name <text>` 用于新建时命名，或恢复时改名。
- TUI 内 `/name` 不带参数时：未命名会话会从**首条用户消息本地生成**一个名字
  （去掉文件块 / 图片标记、折叠空白、最多 60 字符，不额外调 API）；已命名会话则显示
  当前 id、名字和路径。
- `/name <text>` 手动设置或重命名。
- 顶部栏从固定的 `Chat with AI` 改为显示会话名；未命名时显示 `Session <id>`，
  没有 session 时仍显示 `Chat with AI`。

### 🖱️ chat TUI：拖拽复制、边等边写、带建议的拒绝

- **拖拽复制**：左键拖动选中消息区，松手后自动复制。复制结果会去掉 `┃` 左边条、
  工具卡片缩进和显示层自动换行，多行文本粘贴后仍保持原样。按住 `Shift` / `⌥` 仍使用
  终端原生选择，滚轮滚动不变。
- **流式输出期间继续编辑**：回复生成时输入框不再失焦，可以继续输入草稿；此时 `Enter`
  只换行，不会打断当前回复，回复结束后草稿仍在，按 `Enter` 即可发送。
- **拒绝并给建议**：工具确认提示新增 `s`。工具仍不会执行，但模型会在同一轮收到
  `The user rejected this tool call and asked for a different approach: ...`，
  可以立即换工具或换做法，不必再花一轮解释。
- 工具卡片支持单击展开/收起长命令与长输出，`Ctrl+O` 仍然可用。
- 终端标签页标题会同步显示 `chat` / `chat · tool` / `chat · confirm` 等状态。

### 🧠 models：支持 OpenRouter 全部模型类型

`models --type` 现在覆盖 OpenRouter 的 `text`、`image`、`video`、`audio`、
`speech`、`transcription`、`embeddings`、`rerank`、`decision` 等输出类型，并支持
`chat` / `llm`、`music`、`tts`、`stt` / `asr`、`embedding` / `embed` 等别名。

- 修复 `--type chat` 查询 `/models` 却按媒体 schema 解析的问题；
- 保留 `/images|videos/models` 的专用端点用于分辨率、宽高比和参数范围；
  查询价格时切换到 `/models`；
- 标准条目展示 voices、价格、过期时间和 `:free` 标记；
- 修复裸 `--price` 以及 OpenRouter `--price <model>` 的路由；
- 未知类型直接报错并列出支持的类型；APIMart marketplace 仍只接受 image/video/chat。

### 🔊 audio：本地推理支持 `--dry-run`

本地 `speak` / `sfx` / `transcribe` 现在会像在线路径一样遵守 `--dry-run`：
打印解析后的计划，不加载模型、不写 WAV/Markdown 文件。

### 🧹 输出与终端细节

- `-o/--output` 目录不存在时自动创建；没有保存任何文件时返回非零退出码。
- `--save-prompt` 现在覆盖所有 image/video provider，并补齐 video 的参数。
- 无子命令直接运行 `aigc-cli` 时，根命令也会正确接管终端标题与 Ctrl-C 清理，
  与 chat TUI 的 alt-screen / raw mode 不冲突。
- 修复流式回复已经以换行结尾时仍多补一个换行、导致 agent 分隔线前出现空行的问题。
- 修复 `Option+←` / `Alt+B` 在草稿前面全是空白时把 TUI 卡死的问题。
- `--json` 与图片 `@` 附件同时使用时会直接给出可操作错误，提示改用 `--message`；
  手写多模态 `content` 数组会提示改用 `--inject-json`。

## 行为变化

- `--json` 发送的请求体不做多模态转换：图片附件、`content` 数组现在会明确报错，
  不会再在心深处抛出难以理解的 Go 解码错误。
- `--name` 需要配合 `--save` 或 `--session`；单独使用会报错。
- 会话文件会包含 system prompt / AGENTS.md 内容，默认权限为 `0600`；
  共享或提交 session 文件前请先检查内容。

## 升级提示

- 想保留聊天记录：`aigc-cli chat --save`，之后用输出中的 `Resume:` 命令继续。
- 想关闭工具输出截断：调大 `defaults.chat.session_tool_output_max_bytes`。
- 已有脚本如果混用 `--json` 和图片附件，请改用 `--message`；需要手写多模态内容时使用
  `--inject-json`。
- 会话命名保持 Pi 风格：默认不自动改名；`/name` 无参数只在你主动触发时从首条用户消息
  生成名字。
