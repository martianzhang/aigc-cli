# Release Notes v5.5.0

> 以「AI-friendly CLI」为主的次版本：让 agent 只读 `--help` 和命令输出就能正确操作。
> 无破坏性变更；原有输出行保留，新信息以追加 footer 的形式出现。

## Highlights

### 🤖 非交互安全

之前 `aigc-cli </dev/null` 会挂起，`aigc-cli chat </dev/null` 还会把空输入当成一次真实请求。
现在：

- 非 TTY + 空 stdin 直接报 `no input`，退出非 0，不发请求；
- `--interactive` 必须同时有可用的 stdin/stdout 终端；
- 新增 `--no-tui`，agent 在 PTY 中也能强制单轮模式；
- 新增真实二进制 + `os/exec` + timeout 回归测试，防止再次挂起。

```bash
$ aigc-cli </dev/null
Error: no input: pass -p/--message, pipe text on stdin, or run 'aigc-cli chat --interactive'
Hint: aigc-cli chat -p "hello"
```

### 📖 帮助即规范

Top 10 命令（image / video / chat / music / audio / upscale / ocr / redact / detect / mcp）
的 `--help` 现在固定包含：

```text
Requires: ...
Cost:     ...
Output:   ...
Async:    ...
Recovery: ...
```

根帮助新增“Choose by task”表；每个命令仍有可直接复制的示例。新增 golden 契约测试，
防止字段和示例在后续改动中丢失。

### 🧾 结果 footer

生成/转换命令默认追加一段自描述 footer，不需要 `-v`：

```text
Saved:
  /abs/path/image_task_01_0.png
Model: gpt-image-2 (apimart)
Task: task_01...
Cost: $0.0800
Next: aigc-cli preview /abs/path/image_task_01_0.png
```

- 路径一律为绝对路径；
- `Task` / `Cost` 仅在异步任务或 Provider 返回成本时出现；
- 本地命令写 `Model: local: <model>`，不打印成本；
- `Next` 是 provider-aware 的：APIMart → `aigc-cli task <id>`，
  OpenRouter 视频 → `aigc-cli video --job-id <id>`，ModelScope 等没有任务查询命令的
  Provider 回退到 `aigc-cli preview <file>`；
- 已有输出行保持不变。

### 💡 错误提示可执行

常见运行期错误现在带一行可直接复制的 `Hint:`：

- 缺 key → `export OPENAI_API_KEY=...` / `aigc-cli --print-config`
- 缺 model → `aigc-cli models --type image --provider <name>`
- 缺 provider → `aigc-cli models --list-providers`
- 401/403 → 检查 `--api-key` / `--provider` / `--print-config`，不要重试
- 429 → 等待 `Retry-After` 或切换 provider
- 缺 ffmpeg → 单行安装提示
- 缺本地模型 → `aigc-cli <command> init --model <id>`

### 🔁 任务连续性

异步命令始终打印 task/job id 和恢复命令：

```text
Task: task_01...
Resume: aigc-cli task task_01...
# OpenRouter: aigc-cli video --job-id <id>
```

轮询超时或中断后，可以只凭这行 id 恢复。同步 Provider 没有 task id 时不会伪造，
也不会打印“预计耗时”。

### 🔌 MCP 工具契约

40 个已注册工具全部补齐：

```text
when / requires / cost / returns / example
```

- `mcp --list-tools=all` 会展示每个工具的完整契约；
- 生成/转换类工具返回与 CLI 相同的 footer（路径、模型、provider、task id、成本）；
- `generate_sfx`、`generate_speech`、`generate_image/video/music` 均返回 footer；
- 常见参数错误（缺 key / prompt / input / file_path）带 Hint；
- 用户仍通过 `tools_enable` 按需开启，工具越多不代表全部暴露。

## 工程与测试

- 新增各命令 footer 契约测试（image/video/music/audio/upscale/depth/background）；
- 新增 H4 错误用例：缺 key / model / provider / ffmpeg / 本地模型文件；
- 新增 `internal/cli/hint` 共享错误构造器；
- 完整测试 78 个包通过，`golangci-lint` 0 issues，`docs-check` 52 个文件通过。

## 升级提示

- 无破坏性变更，直接覆盖二进制即可。
- 脚本文本解析不受影响：旧输出行仍在，footer 是追加内容。
- agent/CI 建议显式使用 `-p/--message` 或管道输入；不要依赖裸命令进入 TUI。
- ModelScope 等无任务查询命令的 Provider，恢复路径是重新执行或 `preview` 已有文件，
  footer 不会给出无效的 `aigc-cli task`。
- MCP 工具描述变长（含契约字段）；如果上下文预算紧张，用 `tools_enable` 只开需要的工具。
