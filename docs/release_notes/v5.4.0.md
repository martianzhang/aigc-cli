# Release Notes v5.4.0

> 以「redact 中英双语 NER、更多文件格式与 MCP 文件工具」为主的次版本。
> 同时把 vits-ljs / vits-vctk / whisper-tiny 和新的 bilingual NER 模型统一镜像到
> `martianzhang/aigc-cli-models`。

## Highlights

### 🧠 Redact 中英双语 NER

新增官方模型包 `multilingual-ner`（Davlan mBERT multilingual NER，AFL-3.0，约 174MB）：

```bash
aigc-cli redact init --list
aigc-cli redact init --model multilingual-ner
```

- 中文 + 英文 PER / ORG / LOC / DATE；
- 模型文件已镜像到 `aigc-cli-models`，带 SHA256 校验；
- 支持 `tokencls.model_dir` 加载任意第三方 token-classification ONNX 模型；
- 未知标签（`MISC` / `EVENT` 等）会被忽略，不会误遮；
- 修复 BIO 模型 `I-X → O` 的 Viterbi 转移，英文姓名/机构/地址不再被错误合并。

单次切换模型：

```bash
aigc-cli redact scan file.txt --engine model --model-engine tokencls --tokencls-model multilingual-ner
```

### 📄 Redact 文件格式与 DOCX 覆盖

- 新增 BMP / TIFF 读写；
- `.doc` 自动尝试用 LibreOffice（`soffice`）转换为 `.docx`；未安装时明确报错；
- 动图 GIF 明确拒绝，不再静默取第一帧；
- 加密 / 受保护的 PDF、DOCX 返回明确错误；
- DOCX 新增脚注（footnotes）、尾注（endnotes）、批注（comments）、词汇表（glossary）；
- DOCX 检测到嵌入对象 / ActiveX 时明确拒绝，避免未脱敏的嵌入内容被保留。

### 🇬🇧 英文结构化 PII

新增规则：

- 英文街道地址：`123 Main Street, Apt 4B`；
- 英文护照标签：`Passport No: AB1234567`；
- 英国 NI 号：`AB 12 34 56 C`；
- 美国驾照：`Driver's License: D1234567`；
- 国际电话：`+1 (415) 555-0123`；
- 美国 SSN：`123-45-6789`；
- 年龄：`年龄：35` / `35岁`。

### 🔌 MCP 文件脱敏工具

新增：

- `redact_scan`：扫描 text / DOCX / PDF / 图片，返回 span，不写文件；
- `redact_apply`：脱敏并写文件，支持 `style` / `dpi` / `mapping_path`；
- `redact_restore`：用 mapping 还原 DOCX；
- `redact_text` / `redact_check` 增加 `engine`、`model`、`provider`、`enable`、`disable`；
- `redact_check` 支持 `file_path` 和 `mapping_path`。

### 🎧 音频模型统一镜像

以下模型不再从 HuggingFace 下载，改为 `aigc-cli-models`：

- `vits-ljs`
- `vits-vctk`
- `whisper-tiny`

所有文件均新增 SHA256 校验；已安装的本地文件会自动校验，匹配时不会重复下载。

## 升级提示

- `.doc` 自动转换需要本机安装 LibreOffice（`soffice` / `libreoffice`）；
- DOCX 中的嵌入对象 / ActiveX 不会递归脱敏，检测到会报错，请先移除或导出 PDF；
- 中英混合模型首次使用需下载约 174MB：

```bash
aigc-cli redact init --model multilingual-ner
```

- 全量测试、`go vet`、`golangci-lint` 均通过。
