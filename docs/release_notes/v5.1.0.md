# Release Notes v5.1.0

> 以「Chat 支持 Agent Skills」为主的次版本。
> 本次重点：按需加载 `.agents/skills` 技能、TUI `/skills` 与 `/skill:<name>`、
> `--skill` / `--no-skills` 与配置 `skills` 段，以及跨平台兼容规范。

## Highlights

### 🧠 Chat：Agent Skills（渐进式披露）

Chat 现在支持 [Agent Skills](https://agentskills.io/specification) 规范，并沿用跨客户端约定的
`.agents/skills` 目录，**不新增 aigc-cli 专属技能目录**：

- 用户级：`~/.agents/skills/<name>/SKILL.md`
- 项目级：从当前目录逐级向上查找 `.agents/skills/<name>/SKILL.md`，到仓库根停止

启动时只把每个技能的 `name` + `description` + 路径写入 system prompt；任务匹配时，模型再用
`read` 工具加载完整 `SKILL.md`。未激活的技能正文不会进入上下文，和 Pi 的实现方式一致。

```markdown
---
name: pdf-tools
description: Extract text and tables from PDF files. Use when reading or converting PDFs.
---

# PDF tools

Read `references/formats.md` before converting a document.
Run `scripts/extract.sh` relative to this skill directory.
```

### ⌨️ TUI：`/skills` 与 `/skill:<name>`

- `/skills`：列出当前加载的技能（名称、来源、用途）；
- `/skill:<name> [args]`：显式加载技能，参数追加到技能正文之后；
- `Tab` 补全支持 `/skills` 和每个 `/skill:<name>`；
- `disable-model-invocation: true` 的技能不出现在自动选择目录中，但仍可手动调用。

### ⚙️ 新的 `skills` 配置与命令行参数

```yaml
skills:
  enabled: true          # false = 关闭自动发现与 skills.paths
  paths:                 # 等价于可重复的 --skill，支持文件或目录
    - "~/team-skills"
    - "./my-skills"
```

```bash
aigc-cli chat --skill ~/team-skills --skill ./review.md
aigc-cli chat --no-skills
```

优先级：

- `--no-skills` 完全关闭技能发现与加载，忽略 `--skill` 与 `skills.paths`；
- `skills.enabled: false` 关闭自动发现与 `skills.paths`，显式 `--skill` 仍生效；
- `--skill` / `skills.paths` 在自动发现之后加载，同名时覆盖自动发现的技能；
- 支持 `~/` / `~\` 展开，`--skill` 可重复。

行为细节：

- 只有 `read` 工具可用时才注入技能目录；
- 同名技能：项目覆盖用户，显式路径覆盖自动发现；
- 技能目录在建会话时写入 system prompt，恢复旧会话沿用当时的快照（与 `AGENTS.md` 一致）；
- `-v` 会输出扫描告警和同名冲突信息。

### 🪟 跨平台兼容规范

`SPEC.md` 新增第 9 节「跨平台兼容（Windows / macOS / Linux）」，覆盖路径、目录/文件名、
权限/符号链接/换行、外部命令、测试和检查清单。本次 Skills 实现也按该规范处理：

- 全部使用 `filepath`，`~` 同时支持 `~/` 和 `~\`；
- Windows 路径比较使用 `strings.EqualFold`；
- 测试通过注入 `skillHomeDir` 隔离用户目录，不依赖 `HOME`（Windows 读 `USERPROFILE`）；
- CI 继续在 Linux、macOS、Windows 三端运行完整测试。

## 升级提示

- 无破坏性变更；不配置 `skills` 时行为与之前一致（只是自动发现 `.agents/skills`）。
- 如果使用 `--no-skills`，所有技能（包括 `--skill` 指定的）都不会加载。
- 大型技能库建议精简 `description`，或用 `disable-model-invocation: true` 隐藏冷门技能，
  避免 system prompt 中的技能目录过大。
