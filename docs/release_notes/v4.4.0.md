# Release Notes v4.4.0

> 一次偏"补齐细节"的小版本：修复 `chat` 管道输入被丢弃的老问题，搜索新增腾讯云元宝（WSA），提示词灵感新增 YouMind 数据源，并补充主密钥多机迁移文档。**含 2 处行为变更**（见文末）。

## Highlights

### ⌨️ `chat`：管道输入不再被丢弃

此前 `aigc-cli chat` 能检测到 stdin 不是终端，却**从未读取它**，于是 `echo "hi" | aigc-cli chat` 会发送一个空的 `messages` 数组——请求"成功"，但模型什么也没收到。

现在非终端 stdin 会被完整读取（去除首尾空白），作为**最后一条 user 消息**发送：

```bash
echo "解释这段代码" | aigc-cli chat
aigc-cli chat < prompt.txt
git diff | aigc-cli chat --message "帮我写 commit message"
```

- 与 `--message` 同时使用时按顺序拼接：多个 `--message` 在前，管道内容作为最后一条 user 消息；
- 管道内容同样经过 `@file` 展开与 `read_deny` 策略，行为与 `--message` 一致；
- 走 agent loop（而非一次性裸请求），工具调用在管道模式下同样可用；
- `--json`（含 `--json -`）自己占用 stdin，不会重复读取；
- 交互式终端下 stdin 仍归 TUI 所有，不受影响。

### 🔍 `search`：新增腾讯云元宝搜索（`wsa`）

支持腾讯云元宝搜索的 API KEY 模式（`POST /SearchPro`，`Authorization: Bearer <KEY>`）：

```yaml
providers:
  tencent:
    type: wsa
    api_key: "sk-xxx"      # 也可用 TENCENTCLOUD_WSA_APIKEY 环境变量

defaults:
  search:
    provider: tencent
```

```bash
aigc-cli search "golang context timeout" -P tencent
aigc-cli kb search "vector database" -P tencent
```

- `Pages` 是 JSON 字符串数组，逐条解析为 title/url；
- `Cnt` 只接受 10/20/30/40/50，内部按桶映射后再裁剪到调用方 `--limit`，保证 `-n` 精确；
- 认证/配额失败时透出腾讯侧的 `Error.Code` / `Error.Message`，便于定位；
- **仅支持 Search，不支持 Fetch**；chat / MCP 的 `web_search` 可用，`web_fetch` 不适用；
- `--list-providers` 与 `--dry-run`（掩码 curl）均已覆盖。

### 💡 `ideas`：新增 YouMind 提示词源

新增 `--source youmind`，直接调用 YouMind 公开 JSON 接口，**免 API Key**：

```bash
aigc-cli ideas "cyberpunk city" --source youmind
```

- 并发查询图片（gpt-image-2 / gpt-image-2.5 / gpt-6-astra）与视频提示词接口，按来源去重后轮转合并，避免单一媒体类型刷屏；
- 返回完整提示词正文、作者、参考媒体与详情链接；
- 已加入默认的 `--source all`（见文末行为变更）。

### 📚 文档：主密钥多机迁移

新增 [主密钥与多机迁移](../zh/guide-master-key.md)，覆盖 macOS / Linux / Windows 的主密钥导出与导入命令、两种迁移策略、钥匙串条目定位、轮换流程与常见坑。

## 行为变更（⚡ 2 项）

| 变更 | 说明 | 需要做什么 |
|---|---|---|
| **非 TTY stdin 现在会被读取** | 以前管道输入被静默忽略；现在会成为一条 user 消息。若某个脚本把 stdin 用作其他用途（且未使用 `--json`），多出的内容会被当成提问 | 不需要 stdin 时显式 `< /dev/null`，或用 `--json` |
| **`ideas` 的 `all` 增加 YouMind** | 默认多请求一个在线源，与其他在线源共享 12 秒总超时；该源失败只打印 warning，不影响其他结果 | 不想包含时用 `--source` 显式列出（如 `--source local,aipromptslibrary,...`） |

## 兼容性

除上述两项外无破坏性变更：`config.yaml` 无需修改；不配置 `wsa` 时搜索路由与默认厂商不变；`chat --message` / `--json` 的既有行为保持不变。
