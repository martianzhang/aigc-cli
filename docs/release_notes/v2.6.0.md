# Release Notes v2.6.0

## New Features

### `image --decode`：base64 / 格式转换预处理

`--decode`（`-d`）在 provider 无关的层面预处理 `--image-url` 输入：

```bash
# base64 文本文件 / data URI → 内联 data URI（OpenAI 兼容 API 原生支持）
aigc-cli image --decode -i image.txt --prompt "describe it"

# 配合 --output-format 转换图片格式
aigc-cli image --decode -i photo.jpg --output-format webp

# 无 --prompt 时纯本地执行：解码/转换并保存到输出目录，不调 API
aigc-cli image --decode -i image.txt --output-format png
aigc-cli image --decode -i photo.jpg --output-format base64   # 或输出 datauri 文本
```

- base64 文本文件 / data URI → 内联 data URI；真实图片文件与远程 URL 原样透传
- 支持 png/jpg/webp/avif/jxl 相互转换，或输出 base64/datauri 文本
- 核心逻辑提取为 `service.DecodeImageInput`，带表驱动测试

### `image --background transparent`：OpenAI 透明背景

OpenAI / 通用 relay 现在支持 `--background transparent` 生成透明背景图片：

```bash
aigc-cli image --prompt "a logo on transparent background" --background transparent --output-format png
```

- 修复 `sanitizeImageRequest` 错误剥离 OpenAI 的 `background`/`output_format`（该逻辑仅应作用于 Gemini/ModelScope）
- `ValidateBackground()`：transparent 要求输出格式为 png/webp
- MCP 工具 schema 的 `background` 枚举同步更新

### `video --gif`：视频转 GIF

`video` 命令新增 `--gif`，生成后自动把视频转成 GIF，或直接转换本地视频：

```bash
# AI 生成后自动转 GIF（fps=6、调色板 max_colors=128、dither=none，宽度默认 160px）
aigc-cli video --prompt "A man doing push-ups" --gif

# 转换本地已有视频（纯本地、不调 API、不消耗额度）
aigc-cli video --gif -i pushup.mp4              # → pushup_160px.gif
aigc-cli video --gif -i clip.mp4 --gif-width 320

# 高级：追加额外 ffmpeg 参数
aigc-cli video --gif -i clip.mp4 --ffmpeg-flags "-coalesce"
```

- `--gif-width`（默认 160）、`--ffmpeg-flags`（专家逃生门）微调输出
- 缺少 ffmpeg 时打印安装提示，并在提交 API 前提前校验避免浪费生成费用
- 新增 `internal/gif` 包：filter 构建、转换执行、ffmpeg 可用性检查，含表驱动 + 集成测试

### `video --crop-margin`：按边精确裁切

`--crop-margin` 用 CSS margin 简写（逗号分隔）从指定边裁掉像素，去除画面四周边缘：

```bash
# 四边各裁 40px
aigc-cli video --crop-margin 40 -i org.mp4

# 只裁上下 64px（左右保持不动）
aigc-cli video --crop-margin 64,0 -i org.mp4

# 上、右、下、左分别指定
aigc-cli video --crop-margin 40,30,20,10 -i org.mp4

# AI 生成后自动裁边（保留原视频，输出 <stem>_crop.mp4）
aigc-cli video --prompt "a cat" --crop-margin 40

# 与 --gif 组合：转 GIF 前先裁边
aigc-cli video --gif -i org.mp4 --crop-margin 40
```

- **精确裁切语义**：`0` 就是 0——只裁指定的边，其他边不做额外裁切（不恢复源宽高比）
- 单独使用时是纯本地 ffmpeg 重编码（H.264），不调 API；原视频始终保留
- 同时作用于主生成、VEO3 Remix（`--remix`）、`--job-id` 恢复三条路径
- `ffprobe`（随 ffmpeg 安装）用于校验裁边是否超过源视频尺寸
