# Release Notes v4.0.1

> 本版为 Chat 的**工具增强**：新增联网搜索原语 `web_search`（引擎可配置 + `--search-provider`），并让 `web_fetch` 把 HTML 正文转成 Markdown（正文提取、按字符分页），显著降低上下文 token。同时修复了搜索 provider 的 `weight` 被忽略、以及一个受代理环境变量影响的测试。无破坏性变更。

## Highlights

### 🔎 新增 `web_search` 原语（可配置搜索引擎）

Chat 新增联网搜索原语，复用 `kb search` 的 `web_search.*` provider 体系，返回**标题 + URL** 列表（正文用 `web_fetch` 精读）。它是**特权原语**，默认关闭，需在顶层 `tools_enable` 显式开启：

```yaml
tools_enable:
  - "web_search"

defaults:
  chat:
    search_provider: duckduckgo   # 或 auto/free/quality，或 firecrawl/brave/doubao
```

- 新增配置 `defaults.chat.search_provider`（与 `knowledgebase.search_provider` 对齐）；未声明任何 `web_search.*` 时自动使用免费的 DuckDuckGo 兜底，付费引擎缺 `api_key` 会被跳过。
- 新增命令行 `--search-provider` 临时覆盖配置，优先级：`--search-provider` > `defaults.chat.search_provider` > `auto`。
- 单次调用默认返回 5 条、最多 10 条；与 `kb search` 不同，**只搜索、不入库**。

```bash
aigc-cli chat --search-provider brave --message "查一下今天有什么新闻"
```

### 📄 `web_fetch` 将 HTML 正文转为 Markdown

`web_fetch` 抓到的 HTML 现在会先用 readability 提取正文、再转成 Markdown（丢弃导航/页脚等样板），对模型更友好、更省 token：

- **HTML**：readability 提正文 → Markdown；提不到正文时回退为整页转 Markdown。返回文本带 `(markdown)` 标记与 `Title:`。
- **非 HTML**（JSON、纯文本、XML 等）：**原样返回**，不做转换。
- 抓取时附带浏览器 UA/Accept，并按 `Content-Type` 做字符集（charset）解码。
- 分页改为按**字符**（原为字节）：`max_length` 默认 5000、上限 50000，用返回里给出的 `offset` 继续读。
- 复用 `internal/knowledge` 现有的 `codeberg.org/readeck/go-readability/v2` 与 `github.com/JohannesKaufmann/html-to-markdown/v2`，**未新增依赖**。

### 🐛 修复

- **搜索 provider 的 `weight` 被丢弃**：`search.ConfigFromTypes` 未拷贝 `Weight`，配置里的 `weight` 一直不生效（`kb` 与 `chat` 同受影响）。现已修复，按权重随机排序生效。
- **`TestLoad_customFile` 受代理环境影响**：`Load` 把 `http_proxy` 绑定到 `HTTP_PROXY`/`HTTPS_PROXY`，viper 中环境变量优先于配置文件，导致设置了代理的环境下该测试失败。改为在测试内清空这两个环境变量，使断言只反映配置文件内容。

### ♻️ 重构（共享，无行为变化）

- 抽出 `search.RegisterAll`（注册所有 provider + DuckDuckGo 兜底）与 `search.ResolveStrategy`（provider → 策略映射），供 `chat` 与 `kb search` 共用，消除重复实现。
- 新增 `search.NoopQuotaStore`：chat 无知识库数据库时使用，路由器照常做 provider 选择与回退。

## 验证

- `make fmt` / `make build` / `make lint`（0 issues）/ `make test` 全部通过。
- 新增测试：`web_search` 的 provider 路由与命名 provider 优先、`--search-provider` 覆盖配置；`web_fetch` 的字符分页与 rune 边界；以及 `httptest` 端到端（HTML→Markdown 正文提取、样板剥离、JSON 透传、offset 越界）。
- `chat --help` 可见 `--search-provider`。

## 兼容性说明

- **无破坏性变更**。
- `web_fetch` 的 `offset` / `max_length` 语义由「字节」改为「字符」；HTML 页面的返回内容现在为 Markdown（非 HTML 不变）。
- `web_search` 默认关闭（特权原语），需在 `tools_enable` 显式启用。
